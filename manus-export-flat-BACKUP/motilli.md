# Motilli Product Scale

A product-reference sheet for Motilli Celery Juice Fiber Gummies. Use this whenever you're generating ad creative, replicating a reference ad or video, or sourcing/generating B-roll for Motilli, so that every generated image or video accurately represents the real product — the correct container, label, gummy shape and color, and brand palette.

## Product Identity

- **Product:** Motilli Celery Juice Fiber Gummies
- **Category:** Health supplement (gummies)
- **Brand:** Motilli

## Visual Description (use for any generation prompt)

- **Container:** Clear plastic jar/bottle, cylindrical, white screw-top lid
- **Label:** Green/lime gradient background with a white "motilli" wordmark at the top
- **Sublabel:** "CELERY JUICE FIBER GUMMIES" in white text below the brand name
- **Claims on label:** "Verified Clean", a "5g" dosage callout, "GREEN APPLE" flavor
- **Gummies:** Dark green, heart-shaped, translucent/jewel-toned
- **Overall palette:** Green (lime to forest green), white, clean/clinical aesthetic
- **Count:** 60 gummies per bottle

## Reference Image Types to Use

When you have access to real product photography, prioritize (in this order):

1. A hero product shot — clear jar, green label, front-facing. This is the primary reference for any generation that needs to show the whole product accurately.
2. A single heart-shaped green gummy, close-up, ideally on a transparent background.
3. Label close-ups (for getting the wordmark, claims, and typography right).
4. Lifestyle shots — a hand holding gummies, multiple gummies together, a doctor/authority figure holding the product.
5. A high-resolution upscale of the hero shot, if quality is a concern.

## How to Use This

1. Before generating any Motilli creative (static ad, video B-roll, scene replication), locate and load actual product reference photos if the user has supplied them, or ask for them if none are available — never invent the product's appearance from description alone when real photos exist.
2. Load Motilli's brand research (copywriting brief, product/mechanism context, and avatar/voice-of-customer notes) if available, so generated creative reflects the real avatar (GLP-1 users) and mechanism (celery juice fiber) rather than generic supplement tropes.
3. When building an image-to-image or video generation prompt, anchor on the hero product shot as the primary visual reference and use the visual description above to keep every generated angle consistent — same jar shape, same green gradient label, same heart-shaped gummy.
4. Use smart judgment about when to inject product references: if the scene or ad concept is clearly about digestive/supplement content, include the product reference; if it's a b-roll shot of an unrelated lifestyle moment, it may not need the product in frame at all.
5. Keep brand research context (avatar, mechanism, voice) loaded throughout generation so image captions, on-screen text, or accompanying copy stay consistent with the real product story.
