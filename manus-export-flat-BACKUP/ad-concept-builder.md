# Ad Concept Builder — Ads With Intent

This document defines a structured, interactive process for planning a long-form direct-response ad (Facebook ad body copy, advertorial body, VSL script, supplement/device/beverage ad, or any long-form sales narrative) BEFORE any copy is drafted. Use it whenever someone wants to write or plan an ad, ad concept, long-form copy piece, or says things like "write an ad concept," "build me an ad," "new ad for [product]." The old approach of improvising dozens of interdependent rules in one pass produces a different ad every time from the same brief. This process fixes that by making every structural decision explicit and locked in BEFORE a word of copy is written. Once the structural spec is locked, a separate writing pass executes it deterministically — the same spec should always produce the same structural ad.

## GOLDEN NUGGET DOCTRINE (mandatory, apply first)

Before any hook, angle, script, concept, or audit verdict is produced, name the **golden nugget**: the single most emotionally loaded DEEP FRAME in the research — the real motive that makes buyers act — never the surface theme.

- **Topic ≠ motive.** "Memory loss" is a topic (surface hook: "my memory feels as young as when I was 25"). The frame is: "I thought I was getting dementia just like my mum did, until I discovered this." Surface angles buy mild hope/curiosity; deep frames trigger identification so strong the reader feels caught.
- **The test.** For every candidate angle ask: is this the topic, or is this the motive? If it's the topic, dig one layer deeper (memory loss → becoming my parent; GLP-1 bloat/constipation → exiled from my own dinner table; weight loss → the stolen victory).
- **Where it goes.** The golden nugget LEADS — very top of the piece, as the hook. Never buried in the body.
- **Deliverable.** State the golden nugget in one explicit sentence BEFORE drafting. When analyzing a reference ad/funnel/swipe instead of writing, state the nugget it's built on and whether it leads with it. If the research hasn't surfaced one, mine reviews, voice-of-customer data, or forums until it does — never default to a surface angle.

## The 7 structural slots

An ad is assembled from 7 slots. Each slot has a small library of named options (below). Awareness level × sophistication stage × angle pre-selects a recommended default for each slot; the user confirms or overrides.

| # | Slot | What it decides |
|---|------|-----------------|
| 1 | Concept / vehicle | The narrative container + narrator |
| 2 | Lead | How line 1 hits |
| 3 | Mechanism intro | How the root-cause mechanism is revealed |
| 4 | Solution intro | How the product enters |
| 5 | Proof / results | How belief is earned |
| 6 | CTA type | The close — funnel-aware |
| 7 | Length / ratio | Pacing envelope + word band |

## How to use this

1. **Load context.** Gather the brand/product brief: avatar description, awareness level, sophistication stage, the angle (the emotional wound this ad presses), and the product/offer. If any of this is missing, ask for it directly: avatar, awareness level, sophistication stage, angle, and the destination the ad sends traffic to.
2. **Determine the destination.** Ask or confirm where the ad sends traffic — this drives the CTA slot. Options: advertorial, listicle, PDP/product page, presell/quiz, VSL landing page.
3. **Propose defaults.** Using the awareness/sophistication/destination guidance embedded in each slot section below, compute a recommended option for all 7 slots.
4. **Present the 7 slots to the user for confirmation**, one recommended default per slot plus the other viable options for that awareness level. Batch these into one or two rounds of questions rather than firing them one at a time. Do not skip this step — the prompting IS the product, it's how the user's intent gets encoded into the ad before any copy exists. If the user says "just use your defaults," accept all recommendations and proceed.
5. **Assemble the Ad Concept Spec** (format below). Echo it back so the user sees every locked decision in one place before drafting begins.
6. **Write the ad from the locked spec.** Execute the spec deterministically — do not re-decide any slot mid-draft. If the copy seems to need a different structure once you're writing, stop, revise the spec, and restart the draft from the updated spec — don't improvise the structure while drafting.

## The Ad Concept Spec (the artifact)

Produce this as a short document before writing any copy:

```
# AD CONCEPT SPEC — <brand> / <product>
Avatar:           <one line>
Awareness:        <unaware | problem-aware | solution-aware | product-aware | most-aware>
Sophistication:   <1-5>
Angle (wound):    <the emotional wound this ad presses>
Destination:      <advertorial | listicle | PDP | presell/quiz | VSL>

SLOTS
1. Concept/vehicle:  <option>   — narrator: <archetype>
2. Lead:             <option>   — opening line direction: <1 line>
3. Mechanism intro:  <option>
4. Solution intro:   <option>   (integration position: <Ghost|Whisper|Discovery|Conviction|Full-Court>)
5. Proof/results:    <option(s)>
6. CTA type:         <option>   — exact CTA language: "<...>"
7. Length/ratio:     <ratio>    — target band: <N–N words>

HOOK: <the chosen hook line, if one already exists; otherwise the lead slot generates it>
NOTES: <any avatar-specific constraints, banned claims, brand voice notes>
```

## Rules

- **One option per slot.** No "and/or." Intent means a single chosen path.
- **Awareness governs.** An option not viable for the avatar's current awareness level should not be the default. The user can still override it, but flag when an override fights the avatar's awareness level.
- **The spec is the contract.** Whoever writes the copy must obey it exactly. If the copy needs a different structure, change the spec and restart — don't improvise mid-write.

## Slot 1 — Concept / Vehicle

The narrative container and the narrator who carries it. Pick ONE. No two ads in the same set should share a concept+narrator pair. Each option: when to use, the narrator, an example spine, and a directive for the writer.

**C1. Credential Confession**
- When: sophistication 3-5, skeptical avatar, authority-subversion angle. Strong for solution/product-aware.
- Narrator: an insider whose expertise IS the system they now question (pharmacist, nurse, cardiologist, formulator).
- Spine: "I spent 28 years inside [system]. Then I saw what it was actually doing." Authority → disillusionment → discovery → quiet recommendation.
- Directive: the narrator's credibility comes from BEING the system. The turn is discovering they were wrong from the inside. Never breaks character into "ad voice."

**C2. Witness Testimonial**
- When: problem-aware, emotional/relational angle (shame, isolation, watching a loved one). Any sophistication.
- Narrator: someone watching the sufferer — spouse, adult child, friend.
- Spine: observed decline → the moment it became unbearable → the thing that changed → who they have back.
- Directive: the emotional power is in the observer's helplessness and relief. Product enters as "what I found for them."

**C3. Investigative Reveal**
- When: solution-aware, high sophistication, "everything you've been told is wrong" angle.
- Narrator: a researcher/skeptic figure digging for the real cause.
- Spine: the official story → the anomaly that doesn't fit → the hidden mechanism → the overlooked solution.
- Directive: reads like an exposé, not a pitch. Mechanism is the hero; product is the conclusion of the investigation.

**C4. Transformation Story (First-Person)**
- When: problem-aware, identity/quality-of-life angle. Sophistication 1-3.
- Narrator: the sufferer themselves, past tense, looking back.
- Spine: grounded ordinary life → erosion → crisis → stumble onto the fix → progressive return to life.
- Directive: most universal vehicle. Lives or dies on scene specificity and emotional honesty. Avoid montage; stay in moments.

**C5. Authority Disruption**
- When: unaware/problem-aware, "the experts are missing this" angle. Sophistication 2-4.
- Narrator: a practitioner publicly breaking with their field.
- Spine: "I'm a [authority]. I'm about to lose colleagues for saying this." → reframe → mechanism → recommendation.
- Directive: the tension is professional risk. The narrator has something to lose by telling the truth — that's the credibility engine.

**Selection note:** the concept locks the narrator, which locks the voice. Everything downstream (lead, mechanism intro, close) must sound like the SAME person.

## Slot 2 — Lead (the opening)

How line 1 hits. The lead must (a) open ON the problem, (b) have no throat-clearing, (c) match the avatar's CURRENT awareness, (d) make the avatar see herself in line 1. Pick ONE. If a hook already exists from prior hook work, the lead must CONTINUE it (same narrator, same open loop, same emotional temperature) — don't generate a competing opener.

| Code | Lead | Directness | Example | Best awareness |
|---|---|---|---|---|
| L-A | Story | most indirect | "I bought a jacket at Goodwill last Saturday." | any |
| L-B | Problem-Solution | medium-direct | "Deep lines around your mouth no cream touches." | problem / solution |
| L-C | Secret | medium-indirect | "Your LDL is the LAST thing to change. By the time it's high, the damage is done." | solution |
| L-D | Proclamation | indirect | "90% of people on BP meds 20+ yrs die from the exact thing the meds were meant to prevent." | unaware / problem |
| L-E | Confession | indirect | "I've been a pharmacist 28 years. I trusted the system for all of them." | solution / product |
| L-F | Witness | indirect | "My mother-in-law sat alone at the far end of the table. Nobody told her why." | unaware / problem |
| L-G | Timestamp | flexible | "At 2:19 AM I typed 'can atorvastatin cause liver damage' into Google." | problem / solution / product |
| L-H | Failed-Attempt Catalog | medium-direct | "Beetroot for 7 months. Every morning. BP didn't move." | solution |
| L-I | Paradox | indirect | "He did everything right for 20 years. Marathon shape. Dead at 54." | problem / solution |
| L-J | Child Truth | indirect | "'Grandma, why do old people smell funny?' — loud enough for the whole table." | unaware / problem |
| L-K | Authority Disruption | flexible | "I'm a cardiologist. A patient walked in with a bag of 11 supplement bottles." | problem / solution / product |
| L-L | Death/Loss | indirect | "My husband died at 63. Stroke. They said it was sudden. It wasn't." | problem |
| L-M | Cost | medium-direct | "$197 a month on BP supplements. 8 bottles. Numbers hadn't moved in 5 months." | solution / product |

**Awareness → viable leads (the picker constraint):**
- Unaware: Story, Proclamation, Confession, Witness, Child Truth. Avoid: Problem-Solution, Failed-Attempt, Cost.
- Problem-aware: Story, Problem-Solution, Confession, Witness, Paradox, Child Truth, Timestamp, Death/Loss. Avoid: Failed-Attempt referencing solutions she hasn't tried.
- Solution-aware: Secret, Failed-Attempt, Problem-Solution, Timestamp, Paradox, Authority Disruption, Cost. Avoid: Proclamation.
- Product-aware: Timestamp, Witness, Confession, Authority Disruption, Cost. Avoid: Proclamation, Secret.
- Most-aware: open on the offer/identity, not discovery — use Confession or Timestamp lightly, then move fast to CTA.

**Throat-clearing test:** delete line 1. If the hook is stronger without it, line 1 was preamble. Keep deleting until removal makes it weaker.

## Slot 3 — Mechanism Introduction (the discovery story)

HOW the root-cause mechanism is revealed to the reader. This is the belief-shift engine — the moment the reader stops blaming themselves and starts blaming the real cause. Pick ONE. Mechanism must arrive THROUGH the narrative, never as a labeled framework or bullet lecture.

**M1. Research-Scene Stumble**
- When: problem/solution-aware, narrator is the sufferer or a layperson.
- Reveal: narrator, desperate, falls down a 2 AM research hole and trips over the overlooked cause. The reader discovers it alongside them.
- Directive: show the scene (the search bar, the obscure study, the forum comment). The mechanism is found, not announced. One cause, explained in plain language to a smart friend.

**M2. Doctor / Expert Reveal**
- When: sophistication 3-5, authority angle, Credential or Authority-Disruption concept.
- Reveal: an insider explains the mechanism the field ignores — calmly, as someone who's seen it from the inside.
- Directive: authority tone, zero hype. The mechanism's credibility rides on the narrator's standing. Match mechanism depth to the narrator's intelligence.

**M3. Personal-Accident Discovery**
- When: problem-aware, transformation concept.
- Reveal: the narrator changes one thing by chance and the unexpected result forces the question "wait — why did THAT work?" — which surfaces the mechanism.
- Directive: effect first, mechanism second. The accident makes the mechanism feel earned and non-salesy.

**M4. Hidden-Cause Exposé**
- When: solution-aware, "you've been misled" angle, Investigative concept.
- Reveal: systematically dismantles the official explanation, then names the real driver everyone missed.
- Directive: villain teardown is a one-line cause application, not a rant. Build the case like evidence, not accusation.

**M5. Known-Fact Reframe**
- When: any awareness; great for unaware (makes a familiar thing suddenly threatening or hopeful).
- Reveal: takes something the reader already accepts and flips its meaning, exposing the mechanism hiding in plain sight.
- Directive: "You already knew X. What no one told you is that X is exactly why Y." The shift is reinterpretation, not new data.

**Law (all variants):** emotional clearing BEFORE mechanism — the reader must feel understood before they'll accept a new cause. Then a cause-and-effect chain, plain language, no named framework, no "ad mode."

## Slot 4 — Solution Introduction (how the product enters)

HOW hard the product pushes and HOW it appears. Two dials, picked together: integration position (how hard) × entry style (how it shows up).

**Integration position (how hard the product pushes):**

| Pos | Name | Product visibility | Use when |
|---|---|---|---|
| P1 | Ghost | barely named | unaware; pure education/advertorial body; product is a footnote |
| P2 | Whisper | quiet discovery | problem-aware; mechanism-dominant; product is "the thing that happened to contain it" |
| P3 | Discovery | research conclusion | solution-aware; product is what the investigation lands on |
| P4 | Conviction | fully resolved | product-aware; reader already knows the category, product gets a confident case |
| P5 | Full-Court | maximum integration | most-aware / PDP-bound; ingredients, offer, proof stacked |

**Entry style (how it shows up):**
- E1. Stumbled-Upon — the narrator finds it by accident, not by searching for a product. Lowest sales-resistance. Pairs with P1-P3.
- E2. Inevitable Stumble (hybrid) — the mechanism logically demands a solution with property X; the product is introduced as the thing that happens to have X. Pairs with P2-P4.
- E3. Research Conclusion — after evaluating options, this is what survived the criteria. Pairs with P3-P4.
- E4. Direct Confirmation — name it, confirm it solves the established problem, move on. Pairs with P4-P5.

Always follow product entry with a confirmation beat (the small proof the discovery was real) and, if the category is crowded, a one-line category differentiator (why THIS one, not the shelf of alternatives).

**Pairing guidance by awareness:**
- Unaware: P1-Ghost × E1-Stumbled. The reader can't be sold a product they don't know they need; teach first.
- Problem-aware: P2-Whisper × E1/E2. Build the solution CRITERIA before the product so the reader owns the conclusion.
- Solution-aware: P3-Discovery × E2/E3. She's comparing options — the product wins on the criteria you've built.
- Product-aware: P4-Conviction × E3/E4. She knows it exists — resolve doubts, differentiate.
- Most-aware: P5-Full-Court × E4. Offer, bonuses, guarantee, urgency.

**Law:** the product is stumbled upon, not found. The reader must build ownership of the solution criteria BEFORE the product appears, or it feels pitched.

## Slot 5 — Proof / Results

How belief is earned after the product enters. Up to 1-3 of these may be stacked (unlike other slots), but lead with one primary. Pick in service of the avatar's dominant doubt.

**PR1. Progressive, Life-Measured Results**
- What: results shown as returned LIFE, not metrics. "By week three I slept through the night" beats "reduced by 34%."
- Use: always viable; the default spine. Strongest for problem-aware emotional angles.
- Directive: measure in moments the avatar recognizes (a meal without fear, a walk without stopping). Progressive timeline, not instant miracle.

**PR2. Doctor / Authority Validation**
- What: a credible third party confirms it works/is safe.
- Use: high-skepticism categories, safety-sensitive avatars (50+, medicated).
- Directive: one validation beat, woven into the story — not a credential dump.

**PR3. Second-Person Proof Loop**
- What: turns to the reader: "if you've felt X, then you already know Y is possible for you."
- Use: mid-to-late body, to transfer the narrator's result onto the reader.
- Directive: optional but powerful for conversion. Don't overuse — one loop.

**PR4. Social-Proof Narrative**
- What: others' results shown as story fragments, not a testimonial wall.
- Use: crowded categories; product-aware readers who want to see "people like me."
- Directive: specificity = credibility. Named, situational, sensory — never "5 stars, highly recommend."

**Selection by dominant doubt:**
- "Will it work for ME?" → PR1 + PR3
- "Is it safe / legit?" → PR2
- "Does it actually work for real people?" → PR4
- Skeptical + medicated 50+ → PR2 + PR1

**Law:** results pace progressively and are measured in life, not lab numbers. Proof rides inside the narrative.

## Slot 6 — CTA Type (funnel-aware close)

The CTA is decided by where the ad sends traffic, then dressed in a close style. Two picks: destination (drives the ASK) × close style (drives the EMOTION of the ask).

**A. Destination → the ask.** The CTA must match the next step in the funnel — never ask for the sale the page isn't built to take.

| Destination | The ask | Example CTA language | Tone |
|---|---|---|---|
| Advertorial | keep reading / learn the cause | "Read the full breakdown of why this happens →" · "Here's the article that explains it →" | curiosity, soft |
| Listicle | see the list | "See all 7 reasons most people get this wrong →" | curiosity, enumerated |
| PDP / product page | buy / claim | "Claim yours while it's back in stock →" · "Try it for 90 days →" | direct, ownership |
| Presell / quiz | self-qualify | "Take the 60-second quiz to see if this is your issue →" | participation |
| VSL landing | watch / continue | "Watch how she did it →" · "Continue to the full method →" | momentum |

**Rule:** an advertorial/listicle CTA NEVER says "buy now" — it sends the reader deeper into the funnel ("read this to learn more"). Only PDP-bound copy asks for the purchase. Match the ask to the page.

**B. Close style → the emotion of the ask:**
- CL1. Emotional Circuit — resolves the open loop the lead opened. (default — pairs with any destination)
- CL2. Identity Challenge — "the kind of person who…"
- CL3. Binary Choice — two futures, pick one.
- CL4. The Messenger — "I'm just telling you what worked. Do with it what you will."
- CL5. Quiet Exit — understated, no hard push. (pairs with advertorial)
- CL6. Doctor's Last Word — authority closes. (pairs with Credential/Authority concepts)
- CL7. Life Image — paints the restored life and stops.
- CL8. Permission Close — gives the reader permission to want the fix.
- CL9. Instruction Close — tells them exactly what to do next. (pairs with PDP)

**Pairing by destination (recommended defaults):**
- Advertorial → ask: "read more" · close: Quiet Exit or Emotional Circuit
- Listicle → ask: "see the list" · close: Emotional Circuit
- PDP → ask: "claim/try" · close: Instruction or Binary Choice
- Presell/quiz → ask: "take the quiz" · close: Permission or Identity Challenge
- VSL → ask: "watch/continue" · close: Emotional Circuit or Life Image

**Law:** no P.S. stacks, no detached CTA block. The close is the final beat of the SAME voice — the ask emerges from the story, it doesn't get bolted on.

## Slot 7 — Length / Ratio

The pacing envelope. Length is EARNED, never padded. Pick a ratio and a target word band; hold to it while writing.

**Ratios:**
- R1. Story-Dominant — narrative carries; mechanism is light, woven into scenes. Best for problem-aware emotional angles, Transformation/Witness concepts.
- R2. Mechanism-Dominant — the "why it happens" is the spine; story frames it. Best for solution-aware, Investigative/Credential concepts, skeptical avatars.
- R3. Balanced — alternating story beats and mechanism beats. Default when unsure.

**Target bands (words):**

| Band | Words | Use when |
|---|---|---|
| Short | 500–900 | product-aware/most-aware, PDP-bound, warm traffic |
| Standard | 900–1,800 | most ads; problem/solution-aware cold traffic |
| Long | 1,800–3,000 | high skepticism, heavy mechanism education |
| Ultra | 3,000+ | only when the belief shift genuinely requires it (deeply skeptical, high-ticket, or multi-villain teardown) |

**Defaults by awareness:**
- Unaware → R3 Balanced, Long (education-heavy)
- Problem-aware → R1 Story-Dominant, Standard
- Solution-aware → R2 Mechanism-Dominant, Standard–Long
- Product-aware → R3 Balanced, Short–Standard
- Most-aware → R1/R3, Short

**Law:** what scales with length is DEPTH of scene and mechanism, not number of points. Every sentence carries forward motion — no sentence exists to fill a word count.
