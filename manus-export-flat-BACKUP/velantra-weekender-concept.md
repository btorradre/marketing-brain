# Velantra Weekender — Video Ad Concept & Creative Brief

This document explains how to write a video ad concept and creative brief for the Velantra Weekender (the travel/duffel weekend bag) specifically. Use it whenever asked to write a video ad concept for the Weekender, concept a new travel-bag/duffel ad, or produce a creative brief for this product before handing it to production. It pre-loads the product's context (references, colorways, avatar, positioning, sophistication level) so you don't need to re-derive that from scratch, then walks through a structured intent-gathering flow tuned specifically for a video ad, and outputs a production-ready concept brief. Pair this with the companion Velantra Weekender product-truth document when it's time to actually generate images or video.

## Golden nugget doctrine (apply before writing any hook, angle, script, or concept)

Before producing any hook, angle, script, or audit verdict for this or any other ad, name the **golden nugget**: the single most emotionally loaded deep frame in your research — the real motive that makes buyers act — never just the surface theme.

- **Topic is not the same as motive.** For example, "memory loss" is a topic (a surface-level hook might be "my memory feels as young as when I was 25"). The deep frame might be: "I thought I was getting dementia just like my mum did, until I discovered this." Surface angles buy mild hope or curiosity; deep frames trigger such strong identification that the reader feels personally caught out.
- **The test:** for every candidate angle, ask "is this the topic, or is this the motive?" If it's the topic, dig one layer deeper (memory loss → becoming my parent; bloat/constipation → being exiled from my own dinner table; weight loss → the stolen victory).
- **Where it goes:** the golden nugget leads — it belongs at the very top of the piece, as the hook. Never bury it in the body.
- **Deliverable:** state the golden nugget in one explicit sentence before drafting anything. If you're analyzing an existing reference ad instead of writing a new one, state the nugget it's built on and whether it actually leads with it. If your research hasn't surfaced a real motive yet, keep digging through reviews, voice-of-customer data, forums, etc. until it does — never default to a surface-level angle just because it's available.

## Product context — pre-loaded, do not re-ask the user for this

**Product:** Velantra Weekender (structured weekend/travel duffel)
**Category:** Heritage-look weekender — the "weekend at the coast" bag, the classic Velantra silhouette
**Price band:** $50–$150 (Velantra's accessible-luxury positioning)
**Colorways:** Light Chocolate (multiple angle references) plus additional core numbered variants

### Avatar — the "Velantra Woman" persona ("Caroline," 40–48)

Coastal-affluent professional, anti-logo, "if you know you know" taste. The Weekender speaks to her second-home/coastal-getaway lifestyle — the ferry to a coastal town, the weekend bag that looks expensive on a luggage rack without a visible logo. She buys "fewer, better things that last."

### Market sophistication & awareness defaults

- **Sophistication level: 4 out of 5** — fewer direct dupe/imitation claims than some of the other bags in the line, but travel/weekender is a mature, crowded category. The differentiator is a timeless heritage look plus durability for real travel abuse, at an accessible price point.
- **Awareness stage:** problem-aware → solution-aware for cold audiences; product-aware for retargeting audiences.
- **Angle / wound:** "My weekend bag is either a beat-up gym duffel or a $900 logo bag I'm scared to scuff" — the gap between practical and beautiful. The vindication is a weekender that looks heritage-luxury and survives being thrown in the trunk.

## How to use this — the flow

1. **Load the context above** — never ask the user to re-supply the product, colorways, avatar, or positioning; it's already established.
2. **Confirm the format.** Default assumption: a TikTok-style UGC travel vignette (a "pack with me" / weekend-trip video). If an existing video asset for this product exists, mention it and offer to iterate on it rather than starting from zero.
3. **Study any existing reference video asset** for this product (watch it start to finish, note pacing/beats/tone) and/or borrow a beat skeleton from a sibling product's UGC concept if one exists.
4. **Work through the concept-building flow below, framed specifically for video**, using the product-tuned defaults as your starting point — ask the user to confirm or override each slot rather than guessing silently.
5. **Output the Video Ad Concept Brief** in the format given below.
6. **Offer to move to production** once the concept is approved.

## Editor-facing brief rules — hard rule, no exceptions

Any brief that gets sent to an external editor must be fully self-contained. The editor has NO access to your internal files, folders, or local reference libraries. Never put a local file path, internal folder name, or filename that only makes sense inside your own working environment into an editor-facing brief.

**Keep it brief:** briefs sent to editors should be short — roughly 5-6 pages maximum. Do not re-explain the "how to generate this" production process inline in every brief — that process should live once in a separate standing production SOP document that all briefs point to. A brief itself should carry only: the product-truth block, the script, the timeline, the generation prompts, and brief-specific guardrails/QA notes. Cut strategic exposition (why this angle works, why this format was chosen) down to one or two lines — the editor is executing, not deciding strategy.

1. **Product references → live product page links.** Point the editor at the live product page on the brand's website, deep-linking the exact colorway variant if the platform supports it, and name the specific gallery photo to reference.
2. **Creator/talent references → a documented sourcing process** (e.g., a public reference-image source plus an image-generation step to create a similar-but-not-identical creator likeness). Document the process once in a standing SOP, and never attempt to clone a real, identifiable person's face without consent — always generate a distinct, non-identical likeness inspired by the reference.
3. **Reference ads → public links only** (a public ad-library link, a shareable link from an ad-tracking tool, or a direct platform URL) — never a downloaded local video file path. If an internal reference clip has no public URL, describe it beat-by-beat inline instead of linking to it.
4. **No companion files.** Everything the editor needs — segment prompts, scripts, tables — should live inline in the brief document itself.
5. **B-roll (generated scenes) → still-image generation for stills, video generation for motion**, following a documented process with a quality-check gate and the three-variants-then-pick rule described in the companion product-truth document (this applies to macro/product-detail shots too). **The "3D-model" look is banned — if a frame looks like a 3D model or CGI render, it gets regenerated, no exceptions.** Never ship the first roll: generate 3 variants of every scene and pick the one that is not artifacted. The brief itself only needs the final keyframe/motion prompts per scene — never restate the full generation process inline.

Internal reference-file paths remain fine to use for your own internal generation work — this rule only governs what actually gets shown to an external editor.
