# Ad Concept Builder — Ads With Intent

The old way of writing long-form direct-response copy was improvising dozens of interdependent rules in a single pass — which produces a different ad every time from the same brief. This skill fixes that by making every structural decision explicit and locked in **before a word of copy is written.** Once the structural spec is locked, a separate writing pass executes it deterministically: the same spec should always produce the same structural ad.

## GOLDEN NUGGET DOCTRINE (mandatory — apply first, always)

Before any hook, angle, script, concept, or audit verdict is produced, name the **golden nugget**: the single most emotionally loaded DEEP FRAME in the research — the real motive that makes buyers act — never the surface theme.

- **Topic ≠ motive.** "Memory loss" is a topic (surface hook: "my memory feels as young as when I was 25"). The frame is: "I thought I was getting dementia just like my mum did, until I discovered this." Surface angles buy mild hope/curiosity; deep frames trigger identification so strong the reader feels caught.
- **The test.** For every candidate angle ask: *is this the topic, or is this the motive?* If it's the topic, dig one layer deeper (memory loss → becoming my parent; GLP-1 bloat/constipation → exiled from my own dinner table; weight loss → the stolen victory).
- **Where it goes.** The golden nugget LEADS — very top of the piece, as the hook. Never buried in the body.
- **Deliverable.** State the golden nugget in one explicit sentence BEFORE drafting. When analyzing a reference ad/funnel instead of writing fresh, state the nugget it's built on and whether it leads with it. If the research hasn't surfaced one, mine reviews, voice-of-customer data, or forums until it does — never default to a surface angle.

## The 7 structural slots

An ad is assembled from 7 slots. Each slot has a small library of named options. Awareness level × sophistication stage × angle pre-selects a recommended default for each slot; the user confirms or overrides.

| # | Slot | What it decides |
|---|------|-----------------|
| 1 | Concept / vehicle | The narrative container + narrator |
| 2 | Lead | How line 1 hits |
| 3 | Mechanism intro | How the root-cause mechanism is revealed |
| 4 | Solution intro | How the product enters |
| 5 | Proof / results | How belief is earned |
| 6 | CTA type | The close — funnel-aware |
| 7 | Length / ratio | Pacing envelope + word band |

Full option cards (narrator directives, example spines, pairing laws) for slots 1–4 live in `references/concept-lead-mechanism-solution.md`. Full detail for slots 5–7 lives in `references/proof-cta-length.md`. This file carries the condensed decision logic needed to run the process; consult the reference files before finalizing a spec.

## The flow — always run in this order

1. **Load context.** Gather the brand/product brief: avatar description, awareness level, sophistication stage, the angle (the emotional wound this ad presses), and the product/offer. If any of this is missing, ask for it directly.
2. **Determine the destination.** Ask or confirm where the ad sends traffic — this drives the CTA slot. Options: advertorial, listicle, PDP/product page, presell/quiz, VSL landing page.
3. **Propose defaults.** Using the awareness/sophistication/destination guidance below (and in the reference files), compute a recommended option for all 7 slots.
4. **Present the 7 slots to the user for confirmation** — one recommended default per slot plus the other viable options for that awareness level. Batch these into one or two rounds of questions rather than firing them one at a time. Do not skip this step: the prompting IS the product, it's how the user's intent gets encoded into the ad before any copy exists. If the user says "just use your defaults," accept all recommendations and proceed.
5. **Assemble the Ad Concept Spec** (format below). Echo it back so the user sees every locked decision in one place before drafting begins.
6. **Write the ad from the locked spec.** Execute the spec deterministically — do not re-decide any slot mid-draft. If the copy seems to need a different structure once you're writing, stop, revise the spec, and restart the draft from the updated spec — don't improvise the structure while drafting.

## The Ad Concept Spec (the artifact)

Produce this as a short document before writing any copy:

```
# AD CONCEPT SPEC — <brand> / <product>
Avatar:           <one line>
Awareness:        <unaware | problem-aware | solution-aware | product-aware | most-aware>
Sophistication:   <1-5>
Angle (wound):    <the emotional wound this ad presses>
Destination:      <advertorial | listicle | PDP | presell/quiz | VSL>

SLOTS
1. Concept/vehicle:  <option>   — narrator: <archetype>
2. Lead:             <option>   — opening line direction: <1 line>
3. Mechanism intro:  <option>
4. Solution intro:   <option>   (integration position: <Ghost|Whisper|Discovery|Conviction|Full-Court>)
5. Proof/results:    <option(s)>
6. CTA type:         <option>   — exact CTA language: "<...>"
7. Length/ratio:     <ratio>    — target band: <N–N words>

HOOK: <the chosen hook line, if one already exists; otherwise the lead slot generates it>
NOTES: <any avatar-specific constraints, banned claims, brand voice notes>
```

## Rules

- **One option per slot.** No "and/or." Intent means a single chosen path.
- **Awareness governs.** An option not viable for the avatar's current awareness level should not be the default. The user can still override it, but flag when an override fights the avatar's awareness level.
- **The spec is the contract.** Whoever writes the copy must obey it exactly. If the copy needs a different structure, change the spec and restart — don't improvise mid-write.

## Slot 1 — Concept / Vehicle (condensed)

The narrative container and the narrator who carries it. Pick ONE. No two ads in the same set should share a concept+narrator pair. The concept locks the narrator, which locks the voice — everything downstream (lead, mechanism intro, close) must sound like the SAME person.

| Code | Concept | When to use |
|---|---|---|
| C1 | Credential Confession | sophistication 3-5, skeptical avatar, authority-subversion angle; narrator is an insider (pharmacist, nurse, cardiologist) who now questions the system they were part of |
| C2 | Witness Testimonial | problem-aware, emotional/relational angle (shame, isolation, watching a loved one); narrator is an observer — spouse, adult child, friend |
| C3 | Investigative Reveal | solution-aware, high sophistication, "everything you've been told is wrong" angle; narrator is a researcher/skeptic digging for the real cause |
| C4 | Transformation Story (first-person) | problem-aware, identity/quality-of-life angle, sophistication 1-3; narrator is the sufferer, past tense, looking back — the most universal vehicle |
| C5 | Authority Disruption | unaware/problem-aware, "the experts are missing this" angle, sophistication 2-4; narrator is a practitioner publicly breaking with their field |

See `references/concept-lead-mechanism-solution.md` for each concept's full spine and writer directive.

## Slot 2 — Lead (condensed)

How line 1 hits. The lead must (a) open ON the problem, (b) have no throat-clearing, (c) match the avatar's CURRENT awareness, (d) make the avatar see herself in line 1. Pick ONE. If a hook already exists from prior hook work, the lead must CONTINUE it (same narrator, same open loop, same emotional temperature) — don't generate a competing opener.

| Code | Lead | Directness | Best awareness |
|---|---|---|---|
| L-A | Story | most indirect | any |
| L-B | Problem-Solution | medium-direct | problem / solution |
| L-C | Secret | medium-indirect | solution |
| L-D | Proclamation | indirect | unaware / problem |
| L-E | Confession | indirect | solution / product |
| L-F | Witness | indirect | unaware / problem |
| L-G | Timestamp | flexible | problem / solution / product |
| L-H | Failed-Attempt Catalog | medium-direct | solution |
| L-I | Paradox | indirect | problem / solution |
| L-J | Child Truth | indirect | unaware / problem |
| L-K | Authority Disruption | flexible | problem / solution / product |
| L-L | Death/Loss | indirect | problem |
| L-M | Cost | medium-direct | solution / product |

**Awareness → viable leads (the picker constraint):**
- Unaware: Story, Proclamation, Confession, Witness, Child Truth. Avoid: Problem-Solution, Failed-Attempt, Cost.
- Problem-aware: Story, Problem-Solution, Confession, Witness, Paradox, Child Truth, Timestamp, Death/Loss. Avoid: Failed-Attempt referencing solutions she hasn't tried.
- Solution-aware: Secret, Failed-Attempt, Problem-Solution, Timestamp, Paradox, Authority Disruption, Cost. Avoid: Proclamation.
- Product-aware: Timestamp, Witness, Confession, Authority Disruption, Cost. Avoid: Proclamation, Secret.
- Most-aware: open on the offer/identity, not discovery — use Confession or Timestamp lightly, then move fast to CTA.

**Throat-clearing test:** delete line 1. If the hook is stronger without it, line 1 was preamble. Keep deleting until removal makes it weaker.

Full example lines for each lead code live in `references/concept-lead-mechanism-solution.md`.

## Slot 3 — Mechanism Introduction (condensed)

HOW the root-cause mechanism is revealed to the reader. This is the belief-shift engine — the moment the reader stops blaming themselves and starts blaming the real cause. Pick ONE. Mechanism must arrive THROUGH the narrative, never as a labeled framework or bullet lecture.

| Code | Mechanism intro | When to use |
|---|---|---|
| M1 | Research-Scene Stumble | problem/solution-aware, narrator is the sufferer or a layperson; narrator falls down a 2 AM research hole and trips over the overlooked cause |
| M2 | Doctor / Expert Reveal | sophistication 3-5, authority angle, Credential or Authority-Disruption concept; an insider explains the mechanism the field ignores |
| M3 | Personal-Accident Discovery | problem-aware, transformation concept; narrator changes one thing by chance and the result forces "wait — why did THAT work?" |
| M4 | Hidden-Cause Exposé | solution-aware, "you've been misled" angle, Investigative concept; systematically dismantles the official explanation, then names the real driver |
| M5 | Known-Fact Reframe | any awareness, great for unaware; takes something the reader already accepts and flips its meaning |

**Law (all variants):** emotional clearing BEFORE mechanism — the reader must feel understood before they'll accept a new cause. Then a cause-and-effect chain, plain language, no named framework, no "ad mode."

## Slot 4 — Solution Introduction (condensed)

HOW hard the product pushes and HOW it appears. Two dials, picked together: integration position (how hard) × entry style (how it shows up).

**Integration position:**

| Pos | Name | Product visibility | Use when |
|---|---|---|---|
| P1 | Ghost | barely named | unaware; pure education/advertorial body; product is a footnote |
| P2 | Whisper | quiet discovery | problem-aware; mechanism-dominant; product is "the thing that happened to contain it" |
| P3 | Discovery | research conclusion | solution-aware; product is what the investigation lands on |
| P4 | Conviction | fully resolved | product-aware; reader already knows the category |
| P5 | Full-Court | maximum integration | most-aware / PDP-bound; ingredients, offer, proof stacked |

**Entry style:** E1 Stumbled-Upon (accident, lowest resistance, pairs P1-P3) · E2 Inevitable Stumble (mechanism logically demands a solution with property X, pairs P2-P4) · E3 Research Conclusion (survives a comparison, pairs P3-P4) · E4 Direct Confirmation (name it and move on, pairs P4-P5).

Always follow product entry with a confirmation beat (small proof the discovery was real) and, if the category is crowded, a one-line category differentiator.

**Pairing by awareness:** Unaware → P1×E1 (teach first, can't sell an unknown need). Problem-aware → P2×E1/E2 (build solution criteria before the product so the reader owns the conclusion). Solution-aware → P3×E2/E3 (product wins on the criteria you've built). Product-aware → P4×E3/E4 (resolve doubts, differentiate). Most-aware → P5×E4 (offer, bonuses, guarantee, urgency).

**Law:** the product is stumbled upon, not found. The reader must build ownership of the solution criteria BEFORE the product appears, or it feels pitched.

## Slot 5 — Proof / Results (condensed)

How belief is earned after the product enters. Up to 1-3 of these may be stacked (unlike other slots), but lead with one primary.

| Code | Proof type | Use when |
|---|---|---|
| PR1 | Progressive, Life-Measured Results | always viable, the default spine; results as returned LIFE ("slept through the night"), not lab metrics |
| PR2 | Doctor / Authority Validation | high-skepticism categories, safety-sensitive avatars (50+, medicated) |
| PR3 | Second-Person Proof Loop | mid-to-late body, transfers the narrator's result onto the reader — use once, don't overuse |
| PR4 | Social-Proof Narrative | crowded categories; others' results as story fragments, never a testimonial wall |

**Selection by dominant doubt:** "Will it work for ME?" → PR1+PR3 · "Is it safe/legit?" → PR2 · "Does it work for real people?" → PR4 · Skeptical + medicated 50+ → PR2+PR1.

**Law:** results pace progressively and are measured in life, not lab numbers. Proof rides inside the narrative.

## Slot 6 — CTA Type (condensed)

The CTA is decided by where the ad sends traffic, then dressed in a close style.

| Destination | The ask | Tone |
|---|---|---|
| Advertorial | keep reading / learn the cause | curiosity, soft |
| Listicle | see the list | curiosity, enumerated |
| PDP / product page | buy / claim | direct, ownership |
| Presell / quiz | self-qualify | participation |
| VSL landing | watch / continue | momentum |

**Rule:** an advertorial/listicle CTA NEVER says "buy now" — it sends the reader deeper into the funnel. Only PDP-bound copy asks for the purchase.

**Close styles (pick one):** Emotional Circuit (default, resolves the lead's open loop) · Identity Challenge · Binary Choice · The Messenger · Quiet Exit (advertorial) · Doctor's Last Word (Credential/Authority concepts) · Life Image · Permission Close · Instruction Close (PDP).

**Recommended pairings:** Advertorial → "read more" + Quiet Exit/Emotional Circuit. Listicle → "see the list" + Emotional Circuit. PDP → "claim/try" + Instruction/Binary Choice. Presell/quiz → "take the quiz" + Permission/Identity Challenge. VSL → "watch/continue" + Emotional Circuit/Life Image.

**Law:** no P.S. stacks, no detached CTA block. The close is the final beat of the SAME voice — the ask emerges from the story, it doesn't get bolted on.

Full example CTA language for each destination lives in `references/proof-cta-length.md`.

## Slot 7 — Length / Ratio

The pacing envelope. Length is EARNED, never padded. Pick a ratio and a target word band; hold to it while writing.

**Ratios:** R1 Story-Dominant (narrative carries, mechanism light — problem-aware emotional angles) · R2 Mechanism-Dominant ("why it happens" is the spine — solution-aware, skeptical avatars) · R3 Balanced (default when unsure).

| Band | Words | Use when |
|---|---|---|
| Short | 500–900 | product-aware/most-aware, PDP-bound, warm traffic |
| Standard | 900–1,800 | most ads; problem/solution-aware cold traffic |
| Long | 1,800–3,000 | high skepticism, heavy mechanism education |
| Ultra | 3,000+ | only when the belief shift genuinely requires it |

**Defaults by awareness:** Unaware → R3 Balanced, Long. Problem-aware → R1 Story-Dominant, Standard. Solution-aware → R2 Mechanism-Dominant, Standard–Long. Product-aware → R3 Balanced, Short–Standard. Most-aware → R1/R3, Short.

**Law:** what scales with length is DEPTH of scene and mechanism, not number of points. Every sentence carries forward motion — no sentence exists to fill a word count.
