# Velantra Performance Max image prompts

All campaign images were created with the built-in image-generation workflow using Velantra catalog photography as identity references. Every prompt required photorealistic quiet-luxury styling, no text, no logo, no watermark, center-80-percent safe composition, and preservation of the source bag's silhouette, materials, hardware, stitching, color, and proportions.

4. Delphine lifestyle: the exact dark-chocolate top-handle bag carried through a minimalist art-gallery foyer.
