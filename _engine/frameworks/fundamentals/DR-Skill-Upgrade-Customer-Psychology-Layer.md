# Skill Upgrade: Customer Psychology Layer

**Purpose:** Ready-to-paste upgrade blocks that add a customer psychology layer to the four DR skills (`long-form-copy`, `video-ad-scripts`, `funnel-analysis`, `ad-assessment`). Also doubles as a standalone reference.

**Why this exists:** The existing skills teach frameworks (awareness, sophistication, 8-beat structure). Frameworks without psychology produce technically correct work that doesn't convert. This upgrade installs the missing layer: nightmare → dream journey, the reframe as pivot, emotional state matching, and visual-verbal congruence.

**How to use:** Copy the relevant block into the relevant SKILL.md at the suggested insertion point. Each block is self-contained.

---

## THE SHARED MENTAL MODEL (Read First)

Every DR piece of creative is a **transport vehicle** from nightmare state to dream state. The script/copy installs **beliefs**. The visuals (for video) install **feelings**. The reframe is the pivot that flips the viewer from nightmare to dream.

**The axis:**

| State | Definition | Beat |
|---|---|---|
| Hovering | Curious, bracing | Hook |
| Nightmare | Seen, aching | Problem Agitation |
| Deep Nightmare | Cynical, burned | Solution Dismissal |
| **Pivot / Reframe** | Shock, relief | UMP |
| Hope Rising | Wanting mechanism | UMS |
| Approaching Dream | Leaning in | Solution Introduction |
| Dream Rehearsal | Pre-living it | Future-Basing |
| Dream | Identified, decided | Close |

**The one question to ask at every paragraph / line / frame:**
*"What emotional state is the reader/viewer in right now, and is this deepening that state or breaking it?"*

If the answer is fuzzy, the work is information. If specific, the work is alive.

## BLOCK 1 — For `long-form-copy/SKILL.md`

**Insertion point:** Immediately after the intro paragraphs, before "## 0. THE NARRATOR DETERMINES THE FORM". Label as "0A. THE CUSTOMER PSYCHOLOGY LAYER (MANDATORY)".

```
## 0A. THE CUSTOMER PSYCHOLOGY LAYER (MANDATORY)

Frameworks without psychology produce technically correct copy that doesn't convert. Before you touch a narrator, a hook, a beat, or a line — you answer the psychology layer. Every line of the copy is governed by it.

### The Journey: Nightmare → Dream

Every direct response ad is a transport vehicle. You pick up the reader in their nightmare state and drop them off in their dream state. Every belief shift is a mile marker on that journey.

- Nightmare State — the specific, visceral, daily reality of the problem.
- False-Solution Landscape — things they've tried and trusted that are now exposed as broken.
- Moment of Reframe (UMP) — the instant their old mental model shatters.
- Hope Installation (UMS) — the new mental model that promises a way out.
- Vehicle Appearance — the product arriving as the obvious carrier of that new model.
- Future Self — the reader pre-living the transformation.
- Dream State — the identity they become.

If the reader cannot *feel* each of those states, the copy is flat. The job is emotional transport, not information transfer.

### The Reframe Is The Copy's Center of Gravity

The single most powerful moment in any piece of DR copy is the reframe — the instant an old belief dies and a new one installs. Example: "It's not stress — it's silica deficiency."

A powerful reframe:
- Names the old frame explicitly (kills the old belief by name).
- Replaces it with something specific (vague reframes don't stick).
- Is novel to this awareness level.
- Creates relief + urgency simultaneously.

Everything before the reframe exists to set it up. Everything after exists to cash it in. Copy without an identifiable reframe sentence has no pivot and will not belief-shift.

### Psychology Varies by Awareness Level

Awareness is not just information — it's emotional history. Match tone to emotional state, not just information state.

- Problem Aware → psychology need: validation.
- Solution Aware → psychology need: explanation.
- Product Aware → psychology need: proof.
- Most Aware → psychology need: belonging.

### The One Question

At every paragraph, ask: "What emotional state is the reader in right now, and is this paragraph deepening it or breaking it?" If the answer is fuzzy, the paragraph is information — cut or rewrite.

### Mandatory Pre-Write Answers

Before the narrator work below, answer in one sentence each:

1. What is the reader's nightmare state — specific, visceral, daily?
2. What is the reader's dream state — the identity they become?
3. What is the reframe (UMP in one sentence) that pivots them?
4. What is their emotional state at their current awareness level?

These four answers constrain every choice that follows.
```

## BLOCK 2 — For `video-ad-scripts/SKILL.md`

**Insertion point:** Immediately after the intro / "Companion skill" note, before "## The Core Principle: Belief Conversation". Label as "## The Customer Psychology Layer (Mandatory)".

```
## The Customer Psychology Layer (Mandatory)

A winning video script is not a sequence of lines — it's a transport from nightmare to dream. Before you write a hook, a beat, or a single line, lock the psychology layer.

### The Nightmare → Dream Axis

Every frame lives on this axis:

| Axis Position | Viewer State | Script Beat |
|---|---|---|
| Hovering | Curious, bracing | Hook |
| Nightmare | Seen, aching | Problem Agitation |
| Deep Nightmare | Cynical, burned | Solution Dismissal |
| Pivot | Shock, relief | UMP / Reframe |
| Hope Rising | Wanting mechanism | UMS |
| Approaching Dream | Leaning in | Solution Introduction |
| Dream Rehearsal | Pre-living transformation | Future-Basing |
| Dream | Identified, decided | Close |

Skip a state and the next one doesn't land.

### The Reframe Is The Script

The single most powerful moment in any video ad is the reframe — the instant an old belief dies and a new one installs ("It's not stress — it's silica deficiency"). It:
- Names the old frame explicitly.
- Replaces it with something specific.
- Is novel to this awareness level.
- Creates relief + urgency simultaneously.

Everything before it sets it up. Everything after it cashes it in. No reframe = no pivot = no sale.

### Visual-Verbal Congruence (Video-Specific)

Video is spoken over visuals. The script carries beliefs; visuals carry feelings. When they drift, the ad dies.

Rule: every visual frame matches the emotional state of the line being spoken.

| Script State | Visual State |
|---|---|
| Hook | Tight face, UGC framing, subtle tension |
| Problem Agitation | Before-state B-roll, dim grade, tight framing |
| Solution Dismissal | Failed-product bottles, tossed gestures |
| UMP (Reframe) | Pattern-interrupt stillness, direct-to-camera, text overlay |
| UMS | Ingredient B-roll (not product), clean editorial |
| Solution Introduction | Casual home framing (not hero shot) |
| Future-Basing | Brighter grade, wider framing, movement — mirrors of the nightmare B-roll |
| Close | Warm direct-to-camera, softest light |

Nightmare frames: tight, dim, close. Dream frames: wide, warm, open. Color grade and framing track the belief shift. Script a line, script the visual beside it.

Diagnostic: mute the ad. If you can still read the emotional journey, visuals are congruent. If muted it looks like one mood, visuals are failing.

### Visual Symmetry: Mirror the Nightmare in the Dream

Strongest ads run two arcs in mirror:
- Hair in brush (nightmare) ↔ fingers through clean hair (dream)
- Pill bottles stacked (nightmare) ↔ single clean ingredient shot (hope)
- Tight claustrophobic framing (nightmare) ↔ wide free movement (dream)

In Future-Basing, deliberately mirror a visual from Problem Agitation. That symmetry is what makes the transformation felt.

### Mandatory Pre-Write Answers

1. Nightmare state (specific, visceral, daily)
2. Dream state (identity they become)
3. Reframe — the single sentence that pivots them
4. Opening visual — where are we when the hook hits?
5. Closing visual — where are we when the close lands?
6. Mirror pairs — which nightmare visuals will get mirrored in future-basing?
```

## BLOCK 3 — For `funnel-analysis/SKILL.md`

**Insertion point:** Immediately after the intro paragraphs, before "## The Anti-Hallucination Protocol". Label as "## The Customer Psychology Layer (Mandatory Diagnostic Lens)".

```
## The Customer Psychology Layer (Mandatory Diagnostic Lens)

Metrics tell you where a funnel leaks. Customer psychology tells you why. Every diagnosis must include both.

### Funnel = Nightmare → Dream Transport

A funnel picks the customer up in their nightmare state and drops them in their dream state. Every stage is a mile marker:

- Hook / Ad Open — hovering, bracing, curious
- Problem Agitation — nightmare deepens, viewer recognizes self
- Solution Dismissal — cynicism peaks
- UMP (Reframe) — pivot; old belief dies, new belief installs
- UMS — hope rising, wanting mechanism
- Solution Introduction — approaching dream
- Future-Basing — dream rehearsed
- Close / Landing / Checkout — identity handoff

A drop after the hook is not just "hook didn't hold" — it's "viewer never entered the nightmare state." Diagnose the emotional failure alongside the metric failure.

### Diagnostic Questions At Every Layer

1. What emotional state is the viewer supposed to be in here?
2. Is the creative actually putting them in that state?
3. If not, which state are they in instead?
4. Does the visual match the verbal at this beat? (video only)
5. Is there a clear, named reframe somewhere in the creative?

### The Reframe Audit (Required)

Locate the single reframe sentence. Check:
- Does it exist? If not → critical finding.
- Does it name the old frame explicitly ("it's not X")?
- Does it install something specific ("it's silica")?
- Is it novel to the targeted awareness level?
- Is it in the right position (after Solution Dismissal, before UMS)?

A creative without a clear reframe cannot belief-shift. That is usually the primary bottleneck even when metrics point elsewhere.

### Awareness-State Emotional Match Audit

Audience temperature must match the creative's emotional pitch:
- Problem Aware → validation. Funnel must open at the problem, not the solution.
- Solution Aware → explanation. Funnel must dismiss past failures by name.
- Product Aware → proof. Funnel must differentiate on density of evidence.
- Most Aware → belonging. Funnel must reinforce identity, not re-sell.

A mismatch between audience temperature and emotional pitch is a primary leak source.

### Visual-Verbal Congruence Audit (Video Only)

- Do nightmare beats have dim grade / tight framing?
- Do dream beats have warm grade / wide framing?
- Do future-basing visuals mirror the problem-agitation visuals?
- Is the reframe delivered in a pattern-interrupt frame?

### Required Output Section

Every diagnosis ships with a "Customer Psychology Findings" block:

1. What nightmare state was the creative targeting?
2. What dream state was it promising?
3. Did it reframe? Where? Is the reframe strong?
4. Where on the nightmare→dream axis did the viewer drop?
5. What emotional state did the creative fail to install?
```

## BLOCK 4 — For `ad-assessment/SKILL.md`

**Insertion point:** Immediately after the opening paragraphs, before "## Anti-Inflation Protocol". Label as "## The Customer Psychology Layer (Mandatory Assessment Lens)".

```
## The Customer Psychology Layer (Mandatory Assessment Lens)

Scoring without psychology produces technically defensible scores that miss whether the ad actually works on a human. Every assessment must audit the psychology layer.

### The Nightmare → Dream Audit

A winning DR ad is a transport from nightmare state to dream state. Audit transport quality:

1. Is the nightmare state rendered specifically? Generic ("feeling tired") scores low. Visceral, daily, recognizable ("I watched my part widen for 3 years") scores high.
2. Is the dream state rendered specifically? Vague ("feel better") scores low. Concrete ("week 2, I ran my fingers through my hair and came out clean") scores high.
3. Does the reader pass through every axis point? Skipping Solution Dismissal or Future-Basing breaks transport.

### The Reframe Audit (Required)

Locate the single reframe sentence. Score it:

- Exists — if absent, hard deduct.
- Names old frame explicitly — "it's not X" beats "it's deeper than you think."
- Replaces with something specific — named cause, not vague.
- Novel to the awareness level.
- Positioned after Solution Dismissal, before UMS.

Missing or weak reframe caps the overall score. No pivot = no belief shift = no sale, regardless of surrounding execution.

### Awareness-State Emotional Match

Match emotional pitch to avatar's emotional state:
- Problem Aware needs validation → opening sells instead of validating → deduct.
- Solution Aware needs explanation → no named dismissals → deduct.
- Product Aware needs proof → no proof density → deduct.
- Most Aware needs belonging → re-explains mechanism instead of reinforcing identity → deduct.

### The Felt-Journey Test

At every paragraph ask: "What emotional state is the reader in here, and is this paragraph deepening or breaking that state?"

If you can't name the emotional state for a given paragraph, it's information, not persuasion — score it down.

### Required Output Block

Every assessment ships with "Customer Psychology Findings" containing:

1. Nightmare state rendering (specific vs. generic) — quoted evidence
2. Dream state rendering (concrete vs. vague) — quoted evidence
3. Reframe location + strength — quoted evidence (or "no reframe found")
4. Awareness-state emotional match — quoted evidence
5. Specific paragraphs that break the felt-journey (information, not persuasion)

No assessment ships without this block.
```

## Why These Upgrades Matter

Without the psychology layer, the skills produce:
- Technically structured copy that reads like a framework execution
- Assessments that grade craft but miss felt-journey failures
- Funnel diagnoses that point to metrics without explaining the emotional break
- Scripts that sound written, not thought

With the psychology layer, the skills produce:
- Copy where every paragraph has a named emotional state and moves the reader along the nightmare→dream axis
- Assessments that catch "no reframe" as a critical finding even when craft scores high
- Funnel diagnoses that name the emotional failure alongside the metric failure
- Scripts that sound like a guide walking someone from nightmare to dream, with visuals that mirror the journey
