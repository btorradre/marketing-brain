# Belief-Shift Diagnostic Checklist

**Purpose:** Single-page operational checklist for diagnosing whether an ad is actually doing its job — shifting the viewer's beliefs — beat by beat. Use this before shipping any long-form DR ad, and during post-launch review if metrics underperform.

**Source intelligence:** Synthesis of Brooks's Loom 1 (fundamentals) + Loom 2 (8-beat structure).

---

## The Core Question

**At every beat of the ad, what belief is being installed, and is the viewer ready to accept it?**

Direct response is not entertainment. Every line has to move a belief. If you can't name the belief a line is installing, the line is waste.

---

## The 8 Beliefs (One Per Beat)

| Beat | Belief Being Installed | Checkpoint |
|---|---|---|
| 1. Hook | "This is worth my attention" | Is the first line specific + novel? |
| 2. Problem Agitation | "That's me" | Does the viewer recognize themselves in the nightmare state? |
| 3. Solution Dismissal | "Everything I tried had a reason it failed" | Are we dismissing the top 3 failed solutions by name? |
| 4. UMP | "The real cause is different than I thought" | Is the UMP *new information* to this awareness level? |
| 5. UMS | "Then I need [mechanism]" | Does the UMS cleanly pair with the UMP? |
| 6. Solution Introduction | "This product delivers the mechanism" | Is the product intro *casual*, not sold-hard? |
| 7. Objection Handling | "It's safe / worth it / will work for me" | Are the top 3 objections handled by name? |
| 8. Close | "Let me try it" | Does the close return to the angle, not the product? |

---

## Diagnostic Questions (Go In Order)

### Pre-Write Diagnostic

- [ ] Who is the sub-avatar? (one pocket, not the whole market)
- [ ] What is the avatar's current awareness level? (PA / SA / Product / MA)
- [ ] What is the market's sophistication stage? (1–5)
- [ ] Did I pull the cell from the Awareness × Sophistication Matrix?
- [ ] Do I know the floor length this cell requires?
- [ ] What is the desire? What is the identification?
- [ ] What angle family am I using?
- [ ] What concept (format) wraps the angle?

If any unchecked, don't write yet.

### Beat-by-Beat Diagnostic

**Hook**
- [ ] Specific (names something concrete)
- [ ] Novel (introduces information the viewer hasn't heard)
- [ ] Opens a curiosity loop (raises a question, doesn't answer it)
- [ ] Matches the awareness level (problem-aware hook for problem-aware avatar)

**Problem Agitation**
- [ ] Uses specific before-state details (not generic "you feel tired")
- [ ] Includes juxtaposition (after-state first, then "let me back up")
- [ ] Includes a timeline (how long this has been happening)
- [ ] Viewer can say "that's me" within 15 seconds

**Solution Dismissal**
- [ ] Names the top 3 things the avatar has already tried
- [ ] Explains *why* each one failed (not just that it failed)
- [ ] Each dismissal points toward the UMP we're about to reveal

**UMP**
- [ ] Is new information for this awareness level
- [ ] Dismisses the old frame explicitly ("it's not X, it's not Y")
- [ ] Installs the new frame in one sentence
- [ ] Makes the viewer think "oh — that's why nothing worked"

**UMS**
- [ ] Is an ingredient or process, NOT the product name
- [ ] Matches the UMP one-to-one
- [ ] Includes bioavailability/absorption/format detail
- [ ] Makes the viewer think "I need this"

**Solution Introduction**
- [ ] Product is introduced casually ("that night I found ___")
- [ ] Not hard-sold
- [ ] Feels like a discovery, not an ad

**Objection Handling (+ Future-Basing)**
- [ ] Top 3 objections handled (price / safety / "will it work for me")
- [ ] Future-based: week 1, week 2, week 3 transformation
- [ ] Includes risk reversal (guarantee, trial period)

**Close**
- [ ] Returns to the angle, not the product
- [ ] Includes a soft CTA
- [ ] Ends on identification (who they become), not features

## Post-Launch Diagnostic (Metrics → Beats)

Use metrics to locate the broken beat, then rewrite that beat only.

| Symptom | Broken Beat | Fix |
|---|---|---|
| 3s hold rate < 30% | Hook | More specific, more novel |
| Heavy drop 3–10s | Problem Agitation | Add juxtaposition, more specific before-state |
| Drop 10–30s | Solution Dismissal | Name actual failed solutions the avatar used |
| Watch time high, CTR low | UMP or UMS | Mechanism isn't differentiated or isn't believed |
| CTR high, ATC low | Solution Introduction too hard-sold | Pull back the sell, rebuild casual discovery tone |
| ATC high, checkout low | Objection Handling | Handle price, safety, fit by name |
| Checkout high, repeat low | Close | Close sold product, not identity |

---

## The One Rule

**Every beat installs one belief. If you can't name the belief, cut the beat. If the belief isn't ready to be accepted, move the beat earlier or add a setup beat.**

Everything else is commentary.
