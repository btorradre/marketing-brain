# Generate product images for Weekender bag — Session Summary

**Date:** 2026-04-08
**Category:** creative-production
**Transcript:** [[conversation-log/transcripts/2026-04-08_generate-product-images-weekender_1bed5471]]

## What Happened

Session focused on planning the generation of product images for a canvas leather top-handle Weekender bag (Birkin-inspired design) available in 3 colors and 4 sizes. The session established the image generation matrix and workflow plan using Nano Banana's image-to-image tool via Chrome.

## Key Decisions Made

- Confirmed 3 colors × 4 sizes = 12 combinations as the generation matrix
- Using existing product shots as source images for image-to-image generation
- Light chocolate size reference images with dimension overlays will serve as the sizing guide
- Nano Banana via Chrome will be the generation tool
- Session ended before actual generation began (planning only)

## Product Details

**Color Variants:**
- **Army Green:** Green canvas body with warm cognac/tan leather trim (3 existing images)
- **Dark Chocolate:** Off-white canvas body with dark espresso-brown leather trim (5 existing images)
- **Light Chocolate:** Off-white canvas body with warm honey-cognac leather trim (5 existing images + 4 size reference images)

**Size Range:**
- Small: 25cm × 22cm × 14cm (compact, square proportions)
- Medium: 30cm × 26cm × 16cm
- Medium-Large: 37cm × 27cm × 17cm
- Large Weekender: 46cm × 37cm × 18cm (elongated proportions)

## Insights & Learnings

- The product has significant proportion changes across sizes — small is compact and square, large is elongated
- Size reference images with dimension overlays provide precise guidance for maintaining accurate proportions during generation
- Using light chocolate size references as the proportional "bible" ensures consistency across all color variants
- Image-to-image workflow allows for maintaining design consistency (color, materials, hardware) while adjusting proportions

## Creative Output

No final images generated in this session — planning and scoping only. The generation workflow was mapped out but execution was pending clarification on two questions:
1. Number of images per color/size combo (2-3 angles vs. single front-facing shot)
2. Folder organization preference (by color vs. by size)
