## Concept and script architecture

A coherent event introduces several distinct looks; questions and live physical reveals make each person a new discovery.

Each encounter repeats a flexible conversation module: complete look → item names → distinctive detail/origin → thanks. Some stop after one answer. Avoid scripted identical endorsements.

## Keep and vary

**Defining grammar:** Meaningfully different wearers/looks; full look before close detail; actual item movement follows questions; return to person before switching encounters.

**Adaptable:** Participant count, event setting, encounter length, detail order and optional captions. A brief answer may remain brief.

## Required asset roles

Distinct authorized participants/looks; actual interview sound; complete gestures and usable ambient handles. No external inserts are required by default.
