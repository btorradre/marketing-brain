## Concept and script architecture

A recurring fictional protagonist carries a desire through a barrier, discovery and ownership payoff; musical branding can form a separate final chapter.

Source: aspirational anecdote → coveted object → barrier/worry → unresolved desire → discovery → future use → value → receipt/try-on → attention → brand refrain → offer. Target new copy follows the current SOP; fictional events and social response stay distinct from proof.

## Keep and vary

**Defining grammar:** Causal character journey, consistent world/identity, deliberate product reveal, expression matching each line and a motivated shift into product/refrain coverage.

**Adaptable:** Runtime, reveal delay, locations, sung/spoken balance, refrain length and offer. No requirement to copy the source’s long product delay or repeated catalogue.

## Beat blueprint

Cues are semantic placeholders. Replace them with exact approved words/actions in the target plan. Dwell ranges are proposed seconds for the named shot/module, not source measurements or a total-runtime promise.

| Slot / communication job | Visible action and style | Placement; enter → leave / return | Proposed dwell; handoff | Why this scene and edit belong |
|---|---|---|---|---|
| N1 — Visible desire | Character performs one purposeful action; coveted look/object becomes clear. **A** | Full-frame primary story; opening action → destination of desire established. | 3–7s per opening action. | Action gives the viewer a goal to follow. |
| N2 — Coveted appearance | Character looks/approaches; change viewpoint to reveal desired design. **A** | Enter on desire description → hold reaction and object recognition. | 4–8s per meaningful view. | Aspirational appearance earns the coming decision. |
| N3 — Supported barrier | Readable obstacle and fitting expression; phone/search if context requires. **A** | Barrier cue → factual/fictional status clear → emotional consequence. | 4–9s action/answer module. | Visible action makes the obstacle specific; no generic distress montage. |
| N4 — Discovery and named reveal | Show exact target product at its introduction; character’s attention connects to it. **A** | Preserve reveal constraint → hold recognizable product → new useful detail. | 4–8s reveal module. | The unresolved desire finds a concrete answer. |
| N5 — Future use and value | Distinct actual/imagined uses and accurate product beauty/detail. **P** | Each named use gets matching action; value graphic only at value cue. | 2–5s use; 3–6s product/price comprehension. | Uses show relevance; hypothetical future pacing is not past customer evidence. |
| N6 — Ownership and payoff | Receipt, try-on and confident styling; complete fastening/gesture. **A** | Actual story purchase → arrival → use, or mark imagined sequence. | 3–7s per action; keep mirrored identity consistent. | The desired ownership feeling is earned through understandable chronology. |
| N7 — Musical brand chapter | Distinct product forms/settings support original refrain. **P** | Enter on planned musical section → exit once brand thought resolves. | 2–4s per distinct view; cap by meaning, not repeated loops. | The communication task shifts from story to brand/product memory. |
| N8 — Truthful offer | Readable product, brand and action in a stable finish. **G** | Offer cue → all facts and instruction readable. | 3–6s proposed hold; longer only if required reading. | A clear decision frame closes the narrative. |

## Required asset roles

Character/world/wardrobe/product continuity sheets; first frame for every distinct scene; voice/music plan with rights; actual offer evidence; separate imagined/actual chronology ledger; aligned final audio.
