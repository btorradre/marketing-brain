# Creative blueprint library

Start with [README.md](README.md), then the [router](skills/creative-diversity-router/SKILL.md). This folder is the canonical, portable home of the 12 concept-family skills and their 14 blueprint/editing-profile pairs.

- For a concrete concept, load its skill, blueprint, editing profile, source audit and both shared contracts. `python3 blueprints.py context PROFILE_ID` prints this reading packet. The files remain ordinary Markdown for harnesses that do not run Python.
- Keep the differences between concepts. Choose by communication job, speaker relationship, visual treatment and pacing; do not impose a common B-roll ratio or cutting rate.
- Source observations, model-assisted audio notes, inferred purpose and proposed target direction are different evidence classes. These references do not establish campaign performance, product claims, AI provenance or reuse rights.
- Preserve exact approved narration. Write the target editing plan before production, with a reason for each visual and each meaningful edit. Current user instructions govern scope and supersede older snapshots.
- The shared production contract preserves GPT Image 2, Google Omni, DaVinci Resolve and Cut Room requirements. HyperFrames and Remotion remain banned. This library does not provision those tools or a live ad-system database.
- Maintain structured definitions in `skills/creative-diversity-router/references/profiles.json`; regenerate the paired documents with its renderer. Run `python3 blueprints.py validate` after changes. Do not edit generated paired documents independently.
- Keep credentials, downloaded full videos, temporary extraction jobs and unrelated brand records outside this distributable folder. Retained source frames are analysis evidence, not production assets.
