## Upload scope

This initial snapshot contains documents, source code, skills, research, editing plans, structured production records, and Obsidian memory notes. Linked workspace skill resources are materialized, and nested application repositories are included as ordinary current files. Their original Git histories remain local.

**The media and other binary files have not been uploaded yet. This is not a complete backup of the folder.** Their file inventory is in [_github-upload/media-pending.json](_github-upload/media-pending.json). The full media upload awaits a storage decision because the workspace contains approximately 154 GiB of binary assets.

Credentials, authenticated browser profiles, installed dependencies, caches, and transient machine state are excluded. Detected credentials in included files are replaced with `[REDACTED_SECRET]` in these upload copies; local working originals are preserved. Sanitized integrations need fresh credentials before use.

Large documents that embed media use Git LFS. Install Git LFS before cloning or run `git lfs pull` after cloning to retrieve their content.

This is a snapshot collected sequentially on September 13, 2026. It does not establish automatic synchronization, a running application, or a live remote memory database. File-level inventory and sanitization records are in `_github-upload/`.
