# Action-first discovery

Read the active tool descriptions rather than assuming a TikTok scraper, downloader or API is installed. Use current accessible search/browser capabilities. A source URL discovered through web search is a lead until its actual media is inspected. Respect access boundaries; if TikTok is inaccessible, report that and continue through available original creator pages or permitted libraries instead of claiming success.

## Expand vocabulary while preserving the shot

Build queries from the required action, creator phrasing, context and visible behavior. Use short variations rather than one giant query with every constraint. The following are query ideas, not actual search results or validated clips.

| Search family | Toilet/cramping example | What it finds |
|---|---|---|
| Literal action | `woman cramps on toilet`, `stomach pain sitting on toilet` | Posts explicitly naming the situation |
| First-person wording | `stuck on the toilet cramps`, `when the cramps hit bathroom` | Creator language instead of advertising terminology |
| Visible behavior | `doubling over stomach pain bathroom`, `holding stomach on toilet crying` | Action-oriented descriptions; inspect because text can overstate the footage |
| Context/community | `period cramps toilet`, `IBS bathroom vlog`, `bathroom cramp reaction` | Relevant communities; labels are discovery terms, not a diagnosis of the subject |
| Original-version search | Creator handle plus topic; inspect original upload or creator-provided clip | A cleaner source, longer action interval or fewer overlays |

Web fallback examples: `site:tiktok.com "cramps" "toilet"` or `site:tiktok.com "stomach pain" "bathroom"`. If a query only returns monologues, try visible verbs and short action/reaction wording. If it returns comedy with exaggerated mugging, search more specific lived context. If it returns mostly text-covered clips, investigate original versions or existing clean libraries; do not loosen the no-text rule.

“No text,” “raw,” “B-roll” and “extreme” can be supplementary queries, but often retrieve stock packs, editing tutorials or compilations. Search for the lived action first and inspect the footage. Hashtags and post text help discovery only; their promises do not count as visible evidence.

## Explore useful branches

1. Check existing approved asset libraries for an exact action before resourcing it.
2. Search several distinct query families and review actual promising posts.
3. Follow a relevant creator/source branch when it offers different footage or an original clean version.
4. Deduplicate mirrors, compilations and repeated clips; preserve the original creator relationship.
5. Stop a branch when it repeatedly produces the same rejected material. Shift action phrasing or source, not the quality threshold.

Use a bounded first pass appropriate to the task, such as three query families and up to twenty distinct promising candidates per beat. This is a research checkpoint, not a mandatory quota or automatic stopping rule. If nothing passes, summarize which gate is missing and make another materially different pass where promising. Do not run identical searches indefinitely or deliver weak substitutes as selected footage.

Broaden flexible details first: incidental room decor, camera angle or wardrobe. Keep the user's required action, subject and setting fixed. A materially different setting can be listed as an explicitly labeled alternative, never an exact match.

## Review and retrieve

Record the canonical post URL, creator, search route and timestamp before temporary media links expire. Record direct media URL only when actually obtained; do not invent downloadable links. Preserve the original file and useful in/out separately where access permits.

Review full action context and choose a qualifying interval. Inspect source motion at normal speed, then frame-step the final short interval for text and decisive action frames. Batch OCR or contact sheets can help locate issues but cannot certify clean frames that were not inspected. If frame access or resolution is insufficient, leave the candidate unverified.

Requesting an uncaptioned master may be a useful next step, but sending a message to a creator requires user authorization. Do not subscribe, purchase, publish or remove attribution simply to complete a search. Record rights uncertainty without turning read-only candidate research into an approval gate.

Sourcing ends with useful selected media, exact timing and a rationale, or an honest specific gap. AI generation is a separate authorized route, not an undisclosed replacement for found TikTok footage.
