# TikTok B-roll Sourcing

Find **a specific action caught in an extreme emotional moment**, with a raw, organic phone-video appearance and no visible text. This is a sourcing specialization that works inside presenter VSLs, podcasts, voiceover ads and other concepts that deliberately use human footage.

The user's **emotional valence** means visible intensity for this workflow. Record it as `EV intensity: 1–5`, with **5/5 required for selection**. Record emotional direction separately: distress, frustration, disgust, shock, joy, relief, etc. The score is an editorial assessment of visible cues, not a psychological measurement, diagnosis or prediction of conversion.

## Non-negotiable selection gates

| Gate | Pass requirement |
|---|---|
| Exact action | The person visibly performs or experiences the requested action in the required context. Talking about it is insufficient. |
| Extreme intensity | The usable moment scores EV 5/5 and is immediately readable at the chosen entry frame. No quiet lead-in or mild substitute. |
| Raw organic appearance | Rawness 4/5 or 5/5 under the [scoring rubric](references/scoring-rubric.md); plausible phone capture and believable behavior. |
| No text | No visible captions, subtitles, headings, stickers with words, usernames, watermarks, logos containing text or other readable lettering in any frame of the selected interval. |
| Usable action | Enough uninterrupted footage for the requested beat, with no contradictory reveal, obstructed key action or missing necessary context. |

These are independent gates, not an averaged score. Virality, extreme facial emotion or attractive lighting cannot compensate for the wrong action, embedded text or a polished stock appearance. If nothing passes, report the gap and continue a meaningfully different search; never quietly lower the standard.

**Every clip selected through this skill must be extreme**, not only the opening hook. The general B-roll skills may allow quieter supporting scenes; this specialized sourcing request does not. It does not make every scene in every unrelated concept extreme or force live action into an animated world.

## 1. Turn the line into an observable sourcing brief

Recover the approved line, story role, audience/subject, required setting, visible action, emotion, useful duration and aspect ratio. Infer ordinary details from the current brief rather than asking for an entire new brief. Distinguish required facts from flexible details before broadening a search.

Write an acceptance sentence: “We need to see **[subject] doing [action] in [context]**, with **[visible extreme cues]**, captured **[plausible phone setup]**. The viewer should understand **[specific implication]** without needing source captions or audio.”

For the user's example, the target is an adult woman visibly seated on a toilet, folded forward with abdominal bracing and an unmistakable pain reaction. A seated bathroom shot alone does not establish cramping; a hand resting on the stomach alone does not establish extreme intensity. A dramatic sofa clip does not meet a toilet-specific brief. Frame for face, posture and setting; explicit exposure is unnecessary to communicate this action. Do not infer a medical cause from the image.

Preserve the target concept's intended human-footage treatment. Use [B-roll storytelling](../broll-storytelling/SKILL.md) for narrative placement and the relevant concept skill for presenter/podcast coverage. This skill determines which sourced action moment qualifies.

## 2. Search for actions and creator language

Use [the search playbook](references/search-playbook.md). Start with existing permitted source libraries when relevant, then current available TikTok search/browser or connected search tools. Discover capabilities before naming a connector or promising downloads. If browser automation is needed, read its available skill first. If direct TikTok access fails, use web search for original TikTok posts and creator pages; label inaccessible results as leads.

Search the literal action, ordinary first-person wording, visible behavior and context separately. Inspect promising creators' relevant posts or original versions when this yields new leads. Popularity helps discovery but is not a quality score. Do not require “no text” in every search query: creators rarely describe the usable visual interval that way.

Track query, source URL, creator, discovered date and review status. Deduplicate reposts and already-rejected sources. Do not describe a title, thumbnail, transcript, automated description or unavailable video as a visually verified match.

## 3. Find and rate the actual usable moment

Watch the candidate in motion, first muted to judge the picture independently, then with surrounding context when available to check whether a joke, reversal or unrelated reveal changes its meaning. Identify action onset, emotional peak and the last useful frame. The whole post may be weak while a short continuous interval passes.

Apply [the scoring rubric](references/scoring-rubric.md) to that interval, not to the creator, diagnosis, subject's supposed internal feelings or the post's performance. Record entry intensity, peak intensity, usable extreme interval, rawness, confidence and timestamped visible evidence. If only one frame is extreme, it is not yet a usable action clip. If the requested duration exceeds the qualifying interval, flag it; do not stretch, loop or slow it down to pretend it fits.

For a hook, the extreme action must already be readable in the first chosen frame. For another beat, enter on the relevant script cue directly into the qualifying moment. Explain why this action conveys the line's stakes or desired response, rather than merely labeling it “high emotion.”

## 4. Verify text-free footage and source context

Inspect the **actual media**, distinguishing player controls from pixels baked into the source. A screen recording of TikTok with UI is not a clean asset. A captioned post may contain an uninterrupted text-free interval; verify its entire usable interval rather than rejecting or approving by the opening thumbnail.

Use dense sampling/OCR to locate possible text, then inspect every frame of the final short selected interval at sufficient resolution to detect lettering, including its first/last frames and moving watermarks. OCR is an aid, not proof of absence. Record reviewed frame range, source timestamps, method and evidence. If only samples were inspected, mark `text-free status: unverified`; do not certify it as clean. Tiny text still violates the requirement when visible/readable.

Prefer an available original clean version from the creator or a permitted library. Do not blur, cover, inpaint or crop away attribution/text and call the result a text-free source. Do not contact creators without the user's authorization. A source with text is a rejected asset or a lead for an original, not a finished selection.

Preserve original post URL, available media URL/file and creator attribution in the ledger even though the selected pixels must be text-free. Record commercial reuse status separately from visual qualification. A public post or clean file is not automatic ad-use permission. Unknown rights need not stop research, but cannot be reported as cleared for production. Do not present illustrative footage as a real customer testimonial.

## 5. Deliver the selection with the reason

Use [the sourcing sheet](assets/sourcing-sheet-template.md). Deliver qualifying matches first, each with a playable original link, exact usable source in/out, local file when legitimately available, EV intensity, rawness, text-review status and **Why this shot, here**. Include a frame preview when useful, but do not substitute it for a playable clip. Separate unreviewed leads, visually qualified sources awaiting rights and production-ready assets.

Explain what the person visibly does, which cues establish extreme intensity, why that action matches the line and why the selected moment starts/ends there. Preserve a short rejected-candidate log so the next search does not repeat weak leads. Do not pad the result with mild, wrong-action or text-bearing footage to reach a quota.

This task sources footage; it does not silently switch to AI generation. If sourcing cannot meet the gates, state the exact missing requirement and propose an explicitly labeled reenactment only as a next option. If generation is subsequently authorized, use the existing GPT Image 2 / Google Omni workflow and preserve the same action/intensity/rawness/text requirements.

Save selections with the concept's editing plan before assembly. When the assignment includes an actual storyboard or edit, follow the existing editing-plan-first, Cut Room and DaVinci Resolve instructions. A sourcing sheet alone does not claim storyboard delivery or an editor operation.
