# Velantra Boat Tote — Product Truth Reference

This document is the locked product-truth reference for the Velantra Boat Tote (also called the "Boatkin" internally), a premium canvas tote bag. Use it whenever generating images, video, or ad creative that shows this specific product, so every generation is anchored on the real, current design rather than an outdated or invented one. It exists because a previous ad shipped showing a design that doesn't actually exist — a costly, avoidable mistake — and the lesson from that mistake is baked into the rules below.

## Product identity

**Category:** Premium canvas tote bag, Birkin-inspired silhouette.

**Visual description** (locked and corrected after a real incident — see the reference-image rule below):
- **Silhouette:** a soft, structured tote with a Birkin-inspired outline — a SOFT, slouchy canvas body with gentle pleats at the lower corners. It is NOT stiff or boxy.
- **Body:** natural cream/ivory canvas, including the fold-over top edge — the top of the bag is ALWAYS cream. There is no wide colored top section, no colored yoke, and no colored leather upper band. If a generated image shows a colored top yoke, that is an invented, incorrect product and must be regenerated.
- **Trim** (thin straps only): two slim colored top handles; one thin colored belt strap running high across the front with a small gold turn-lock at its center (plus two small gold keeper bars); two colored vertical straps running from the belt down the front to the base; a colored trimmed bottom edge. White contrast stitching appears on all trim.
- **Hardware:** only the small gold turn-lock plus the two small gold belt keepers. There is no Kelly-style clasp plate, no large V-straps with silver/gold plate tips, no corner patches, and feet are not visible in most shots.
- **Construction:** cream canvas body with thin colored trim, two-tone — except for the solid colorways, which are the exception and have a fully colored body instead of cream-plus-trim.

## Available colorways

**Two-tone (cream canvas body + thin colored trim):** navy, red, sunny yellow, emerald green, lady pink, light grey, lineman, and additional two-tone options including pink, dark green, olive green, orange, and yellow.

**Solid (fully colored body, no cream canvas):** solid green, solid navy, solid olive green, solid orange, solid pink, solid red, solid yellow.

## Rules & standards

**The reference-image law — this is the most important rule in this document.** When generating any image or video of this product, always anchor the generation on a real, verified-current photo of the specific colorway, never on the text description alone and never on an outdated reference photo. This product previously existed in an earlier design (chunky leather trim, wide colored top sections, fully-colored bodies) that has since been retired and replaced by the current design described above (thin trim, cream top, gold turn-lock only). A real ad was shipped showing the *retired* design because an old reference image was mixed in with the current ones — an expensive, avoidable error. Before starting any generation work on this product:
1. Confirm which reference images in the available product photo library represent the *current, live* product versus the *retired* design — don't assume; verify.
2. Always generate from the current, verified reference photo for the specific colorway being used — never rely on the written visual description as a substitute for an actual reference image.
3. If a pipeline or tool auto-loads reference images from a shared library, double-check it isn't silently pulling in retired-design images alongside current ones — when in doubt, specify the exact current reference image explicitly rather than trusting an automatic selection.
4. Each colorway should have multiple reference angles/shots available (ideally including at least one straight-on/front view and one detail/hardware shot) — use the most direct, unambiguous angle as the primary anchor for any new generation, and cross-check the result against a second angle if the first result looks uncertain.
5. A model-worn/carrying reference shot per colorway is also valuable for lifestyle or UGC-style generations, showing scale and drape on a body.

**General standard**: before delivering any generated image or video containing this product, compare it side-by-side against the verified current reference photo for that exact colorway and confirm every element in the Visual Description above (cream top with no colored yoke, thin trim only, small gold turn-lock only, soft slouchy silhouette) is correctly represented. Any deviation is a defect, not a stylistic choice — regenerate rather than accepting it.
