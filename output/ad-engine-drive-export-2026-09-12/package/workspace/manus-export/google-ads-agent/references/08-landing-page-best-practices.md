# Landing Page Best Practices for Google Ads

## Message Match
- Headline on landing page should echo/match the ad headline
- If ad says "50% Off Running Shoes" → landing page immediately shows running shoes at 50% off
- Same language, tone, terminology
- Primary CTA on page matches ad's CTA
- Don't send all traffic to homepage — use specific, relevant landing pages

## Quality Score Factors
- **Relevance**: Page content matches ad and keyword intent
- **Usefulness**: Valuable, unique content
- **Navigation**: Easy to find what you need
- **Transparency**: Clear about business, data usage
- **Trustworthiness**: Safe, professional
- **Load speed**: Fast on all devices
- **Mobile-friendliness**: Fully functional on mobile

## Speed Targets
- Under 3 seconds (under 2 ideal)
- LCP under 2.5s, FID under 100ms, CLS under 0.1
- Compress images (WebP), minimize JS/CSS, lazy loading, CDN, minimize redirects

## Mobile-First Design
- Design for mobile first, adapt for desktop
- Large tappable buttons (min 48x48px)
- Short forms
- Single-column layouts
- Click-to-call phone numbers
- No intrusive interstitials
- Min 16px font

## High-Converting Landing Page Elements
1. Headline matching ad promise
2. Sub-headline expanding value proposition
3. Hero image/video showing product/outcome
4. Benefit-focused bullet points
5. Social proof above the fold
6. Clear, prominent CTA button
7. Trust signals (SSL, guarantee, return policy, payment logos)
8. Minimal distractions (no nav bar, footer links, sidebars)

## Trust Signals
- Customer reviews/ratings, testimonials with real names + photos
- Client logos, media mentions
- Security badges (SSL, Norton, McAfee)
- Guarantee badges, free shipping badges
- Payment method logos
- Industry certifications, BBB accreditation
- Physical address + phone number
