# Self-audit checklist — run and report before anyone else sees the script

Referenced from SKILL.md's "Self-audit before presenting" section. Run every item below and report the results as a block at the end of the deliverable — do not ship a first draft and wait to be corrected.

1. **Ledger audit** — every belief row shifted, every loop closed. Print the ledger with the "closed at" column filled.
2. **Congruence audit** — hook promise = resolution payoff, same images. Guarantee denominated in the opening image.
3. **Demo audit** — every claim has its demo beat or mechanism attribution.
4. **Proof audit** — nothing invented: no fake studies, Ns, percentages, doctors. Guarantee matches the actual policy.
5. **Source-congruence audit** — the mechanism's messenger doesn't contradict any belief the ad installed.
6. **Simplicity audit** — read aloud, grade level, one idea per sentence.
7. **Literal audit** — zero abstractions, zero metaphors except the sanctioned sensory demo and the canonical analogy set. Every line filmable.
8. **Truth-signal audit** — does every scene carry at least one detail so specific only a person who lived it would know it?
9. **Angle audit** — six-month shelf life, swap test, one awareness level named with the hook as evidence.
10. **Length audit** — print the actual word count and `words ÷ 190 × 60`. Report the runtime that math gives, not the one you hoped for. Over target = cut before showing anyone.
11. **Repetition audit** — list every idea in the script once. Any idea appearing twice is a cut, not a rewrite.
12. **Objection-coverage audit** — print the objection table: every failed solution, its failure mode, and its designated killer. An unanswered objection or a killer with no matching failure mode is a hole.
13. **Criterion audit** (any ad naming an unfamiliar ingredient) — quote the criterion line and confirm it lands BEFORE the first ingredient.
