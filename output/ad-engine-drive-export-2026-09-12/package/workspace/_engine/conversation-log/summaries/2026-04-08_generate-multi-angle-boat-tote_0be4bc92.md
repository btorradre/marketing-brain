# Generate multi-angle boat tote product shots — Session Summary

**Date:** 2026-04-08

**Transcript:** [[conversation-log/transcripts/2026-04-08_generate-multi-angle-boat-tote_0be4bc92]]

## What Happened

Session focused on fixing and regenerating AI-generated product images for a boat tote bag across 14 color variants. The original Navy images were used as source, with AI image-to-image generation creating color variants. This session dealt with QA fixes — correcting navy color bleed, wrong bag shapes, and missing hardware details across multiple colors.

## Key Decisions Made

- Two-image reference approach works best for stubborn color bleed issues (using both the original Navy source and the target color as references)
- Lineman is a cream/ivory tonal colorway — no added color, just the natural canvas
- Each color variant gets images 07-13 (7 angles per color) plus a model shot

## Insights & Learnings

- AI image-to-image color swaps frequently suffer from "source color bleed" — the original navy kept showing through on trims, straps, and interior bands
- The more subtle/neutral the target color (like Lineman cream), the harder it is to eliminate source color bleed
- Hardware details (turn-lock clasps, buckles) sometimes get lost in regeneration and need explicit prompting
- Bag silhouette can drift during regeneration — structured shapes replacing the intended soft slouchy form
