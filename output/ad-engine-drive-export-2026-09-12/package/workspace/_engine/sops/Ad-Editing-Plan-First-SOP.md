# Ad Editing Plan First SOP

Owner: Brooks · Applies to: every brand and all ad-production tools · Last updated: 2026-09-08

## Standing instruction

“When we're making ads, we create the editing plan first. I don't want to have to prompt you to do this.”

Planning is a mandatory production prerequisite, not an optional response to an editing-plan request. Apply it to new ads, adaptations and revisions. Workspace AGENTS.md and the user's latest instructions govern editor/model selection; this SOP does not pick an editor or override those choices.

## Order of work

1. **Intake and recover context.** Read the brand/product truth, brief, exact script if supplied, reference media, selected assets and any existing plan. Honor accepted creative decisions. For resumed work, recover the plan instead of restarting.
2. **Analyze the reference when present.** Inspect the full source. Record its actual frame rate/duration, shot in/out boundaries and representative images. Verify each cut on consecutive frames and inspect transition spans frame by frame. For every shot, map the narration, B-roll/action, movement, caption treatment, incoming transition, handoff to the next shot and purpose. Explain the pacing/energy arc and audio continuity. Automated shot detection and ASR are aids: correct missed cuts, mistaken scene labels and timestamp drift. Separate exact frame measurements, approximate speech timing and creative interpretation. Do not assert retention results without data.
3. **Write the editing plan before production.** Make a line-by-line visual schedule and an overall editing strategy. Use the template below. A script or generation prompt list does not substitute for the plan. If copy is still developing, begin with provisional beats and revise the plan when copy locks; do not spend on assets first and plan around them afterward.
4. **Save and surface it automatically.** Store `edit/editing-plan.md` in the concept directory (or update an existing clearly named equivalent). Save reference evidence beside it under `edit/reference-analysis/` when applicable. Include version/date, inputs, assumptions and unresolved dependencies. Link the plan in the brief/board and give a concise user-facing summary. Keep external editor briefs self-contained where their delivery rules require it.
5. **Produce from the plan.** Use existing authorization; do not invent a new confirmation gate merely because a plan is required. If the user requested a plan-only or plan-first phase, deliver that phase before generation/editing. Existing explicit approvals and actual missing permissions still apply. Source/generate the specified assets, review them, produce/select narration, obtain fresh alignment, then assemble in the chosen editor. Update estimated timings to actual timings before locking cuts and captions.
6. **Revise and verify.** Update the plan before implementing a changed script, voice, asset choice, hook, duration or direction. Preserve prior versions and explain the resulting change. Verify the composed edit and final export against the plan, not only source contact sheets. Record unfinished work accurately.

## Minimum editing-plan template

- **Brief and inputs:** concept, audience, objective, reference/source evidence, exact copy or provisional beats, selected assets, current user constraints, editor, aspect ratio and duration target.
- **Reference findings:** shot/cut map, narration-to-picture pairings, scene handoffs, transition appearance/duration, caption rhythm, internal movement, audio continuity and pacing. Mark “no reference supplied” when appropriate.
- **Editing strategy:** what the hook shows; how the explanation, product reveal and payoff flow; where pacing accelerates or holds; what types of B-roll belong under each idea; why each transition is used.
- **Visual schedule:** one row per spoken line or meaningful beat, using the columns below.
- **Voice and sound:** voice source/direction, pronunciation, continuous versus scene audio, music/SFX roles, mix priorities and fresh alignment requirements. Never represent a substitute voice as a reference clone or assume missing voice rights.
- **Typography and finish:** captions, emphasis labels, safe placement, product identity, offer, CTA and end hold.
- **Production and QA:** reuse/source/generate decisions, missing assets, ordered build steps, editor handoff, export spec and checks of the finished cut.

## Definition of ready for production

The plan exists, every line/beat has a relevant visual/action, asset gaps are explicit, cut/transition/audio/caption decisions are concrete, and timing assumptions are labeled. A collaborator can execute the plan without inventing the ad's structure. Read-only inspection and analysis are allowed while preparing it. Missing information blocks only the work that depends on it, not independent planning.

## Right-sized planning

- **No reference:** create original direction from the brief. Do not invent frame measurements, source clips or reference claims.
- **Static ad:** a compact composition/copy/hierarchy/source/placement/export plan satisfies this rule. No fictitious cuts or voiceover steps.
- **Single hero clip:** a compact action/framing/duration/aspect/source/QA plan is sufficient. Preserve native output when editing is not requested; do not add a timeline simply to satisfy this SOP.
- **Existing ad revision:** update the affected plan rows and dependencies rather than repeating unaffected analysis.
