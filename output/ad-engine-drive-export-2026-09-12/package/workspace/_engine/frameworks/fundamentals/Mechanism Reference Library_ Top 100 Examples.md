## Strategic Prompts for the Agent

When reviewing this list, consider these differentiation strategies:

1. **The Format Pivot:** If you see a high-scoring supplement mechanism, could it be delivered via a transdermal patch, a sublingual spray, or a functional food? How does changing the format improve the *Logical Coherence* (e.g., "bypasses stomach acid for 5x absorption")?
2. **The Specificity Upgrade:** If you see a generic mechanism (e.g., "Probiotics → Gut Health"), how can you make it hyper-specific (e.g., "Akkermansia muciniphila → Mucin layer restoration → Leaky gut repair")?
3. **The Synergistic Stack:** Can you combine two high-scoring mechanisms from different categories into a single, novel product?
