## Loom Framework Stack (2026-04-05)

The principles Brooks teaches on Loom, broken down into operational reference files. These sit directly underneath the DR-SOP and provide the strategy + psychology layer that governs every piece of creative.

### [[fundamentals/DR-Fundamentals-Loom1-Breakdown.md|DR-Fundamentals-Loom1-Breakdown.md]]
The four principles that govern every ad: avatar, awareness levels, market sophistication, and desire/identification/angle/concept. The strategy stack. Read first.

### [[fundamentals/DR-Ad-Structure-Loom2-Breakdown.md|DR-Ad-Structure-Loom2-Breakdown.md]]
The 8-beat ad structure every DR ad follows: Hook → Problem Agitation → Solution Dismissal → UMP → UMS → Solution Introduction → Objection Handling/Future-Basing → Close. The execution spine.

### [[fundamentals/DR-Customer-Psychology-Journey-Reframe.md|DR-Customer-Psychology-Journey-Reframe.md]]
The psychology layer: nightmare → dream journey, the reframe as the pivot, visual-verbal congruence, and the felt-journey test. The layer that makes frameworks work on humans.

### [[fundamentals/DR-Awareness-x-Sophistication-Decision-Matrix.md|DR-Awareness-x-Sophistication-Decision-Matrix.md]]
Combined decision table: which awareness × sophistication cell dictates ad length, beat emphasis, and angle family. Use this as the pre-brief sizer before writing.

### [[fundamentals/DR-Angle-Library-Expanded.md|DR-Angle-Library-Expanded.md]]
Angle families organized by awareness level (doctor-dismissal, hidden-cause, failed-solutions, ours-vs-theirs, identity, etc.) with rotation strategy and saturation warning signs.

### [[fundamentals/DR-Belief-Shift-Diagnostic-Checklist.md|DR-Belief-Shift-Diagnostic-Checklist.md]]
Beat-by-beat QA checklist with "which beat is broken" metric diagnostic. Run this before shipping any long-form DR ad.

### [[fundamentals/DR-Visual-Analysis-Silica-Hair-Loss-Ad.md|DR-Visual-Analysis-Silica-Hair-Loss-Ad.md]]
Timestamped visual-script congruence breakdown of the Nour hair-loss ad (the one Brooks walked through in Loom 2). Worked example for every concept in the other files.

### [[fundamentals/DR-Skill-Upgrade-Customer-Psychology-Layer.md|DR-Skill-Upgrade-Customer-Psychology-Layer.md]]
Ready-to-paste psychology upgrade blocks for the long-form-copy, video-ad-scripts, funnel-analysis, and ad-assessment skills. Drop in at noted insertion points.

**When to use this stack:**
1. Starting a new creative → read Loom1 (strategy) + Decision Matrix + Angle Library.
2. Writing a script → read Loom2 (structure) + Customer Psychology + Visual Analysis.
3. QAing a draft → run Belief-Shift Diagnostic Checklist.
4. Onboarding a new team member → this stack is the fastest path to how-we-think.
