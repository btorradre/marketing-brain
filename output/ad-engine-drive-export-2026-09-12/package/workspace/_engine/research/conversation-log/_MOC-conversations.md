# Conversation Log — Map of Content

> Every marketing-related Claude session that touches this vault gets automatically logged here — full transcript + distilled summary. This is the system's memory. Every insight, every decision, every creative direction lives here and is searchable.

---

## How It Works

The `conversation-logger` scheduled task runs every evening at 10 PM. It:

1. Pulls the list of recent Claude sessions
2. Identifies sessions related to marketing work (ad copy, hooks, funnels, creative strategy, competitor analysis, etc.)
3. Reads the full transcript of each qualifying session
4. Generates a summary note with key decisions, insights, creative output, and action items
5. Saves both the full transcript and the summary into this folder
6. Tags everything for searchability

## Folder Structure

- **`/summaries/`** — Distilled notes: key decisions, insights, action items, creative output references. Start here.
- **`/transcripts/`** — Full conversation transcripts for deep reference. Go here when you need the exact back-and-forth.

## Key Tags

- `#session-log` — All logged sessions
- `#creative-production` — Sessions where ads/scripts/copy were written
- `#competitor-analysis` — Sessions analyzing competitor ads or brands
- `#strategy` — Sessions about angles, mechanisms, market positioning
- `#skill-development` — Sessions building or updating skills
- `#funnel-work` — Sessions about funnel architecture or optimization
- `#research` — Sessions doing avatar research, Reddit scraping, etc.
