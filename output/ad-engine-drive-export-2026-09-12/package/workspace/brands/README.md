# Brands

Every brand here has the **identical** structure defined in [[_TEMPLATE/README]]. That uniformity is what lets skills run on any brand by name.

To launch a new brand: `cp -R brands/_TEMPLATE brands/<newbrand>`, fill in `00-brief.md`, drop the hero image in `brand/`, and register it in the skill registries.
