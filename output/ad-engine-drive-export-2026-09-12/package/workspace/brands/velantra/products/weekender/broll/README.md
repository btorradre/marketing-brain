# Weekender content library

Consolidated 2026-08-02. Clips that used to be buried inside individual concept folders now live here so any concept can pull from them. A good clip generated for one voiceover ad is a good clip for the next one.

## Layout

| Folder | What's in it |
|---|---|
| `broll/` | Every reusable clip. No burned-in text, no creator on camera. This is what you scrub when cutting. |
| `broll/creator/` | Clips with a creator's face on camera. Tied to a specific avatar and a specific read, so they are kept separate from the b-roll proper. |
| `../images/` | Keyframe stills, same provenance prefixes. |

## Naming

`<concept-slug>-<original-filename>.mp4`. The prefix is the concept the clip was generated for, so provenance survives the move.

| Prefix | Concept | Engine |
|---|---|---|
| `askme` | ask me a question review (7/24) | Seedance |
| `built` | built where bags break, craft film (7/24) | Kling |
| `girlmath` | girl math, Vestirsi Bella replication (7/28) | Google Omni |
| `onroute` | on route NYC, Vestirsi replication (8/1) | Google Omni |
| `buildvo` `fitvo` `packvo` | build / fit / pack VO (7/10) | Seedance via kie |
| `blair` | Blair testimonial (7/10) | Seedance via kie |

Unprefixed files are the original general b-roll from July and predate the consolidation.

## What deliberately stayed behind in `concepts/`

Finished ads, reference swipes, rejected and superseded takes (`_v1-6s/`, `_v1_rejected/`, `_superseded/`), caption overlay PNGs, briefs, and the `picks.json` / `manifest.json` files that describe a specific run. The `chloe launch directors cut` concept was skipped entirely.

Reversal manifest for the 143 moved files: `../_consolidation-manifest-2026-08-02.json`.

## Before reusing a clip

The product truth still applies. Check any clip you pull against the `velantra-weekender` skill, especially: gold hardware on both clasp plates, no zipper, no logo, hand or forearm carry only, and the leather and canvas split sitting in the same place whether the bag is open or closed.
