## 10. Guardrails + QA (hard rules)

1. Script verbatim. "boatkin" never corrected or swapped for a real brand name. No other brand/designer bags anywhere.
2. Product is always "The Sofia Woven Tote" / "the Sofia."
3. No country-of-origin claims anywhere.
4. **Truth discipline:** the sale price and the two sold-out swatches must be visibly true on the live page the day you record. If either has changed, stop and flag.
5. Every voice reads over 40; every face reads 35–40; all three avatars distinct from each other and every boatkin-series creator.
6. Two-engine discipline: avatar = Pinterest + Nano Banana Pro; b-roll = GPT Image 2 + Omni. Never one hybrid prompt, never skip the keyframe step.
7. Raw iPhone lighting on every generated shot, including macros — regenerate anything that reads studio-lit or "professional."
8. Never reproduce the Pinterest photo's exact face — original identity only, that person never named or credited.
9. Never animate the flap opening/closing or straps unfastening — state is locked in the keyframe for the whole clip.
10. If a generation fails 3x, substitute a real gallery photo with a push-in — never stretch a neighboring clip.
