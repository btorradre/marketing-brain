# Sofia (Straw Tote) content library

Consolidated 2026-08-03. Reusable product clips that used to be buried inside individual concept folders and the brand-level `videos/` replication runs now live here, so any AI voiceover concept can pull from them.

## Layout

| Folder | What's in it |
|---|---|
| `broll/` | Every reusable clip. Product-focused only: product stills-in-motion, macros, open-bag and packing shots, and model-with-bag footage where nobody addresses the camera. No burned-in text. |
| `broll/creator/` | Clips with a creator face-on to camera, tied to one avatar and one UGC read. Kept out of the b-roll proper. |

`<concept-slug>-<original-filename>.mp4` so provenance survives the move.
