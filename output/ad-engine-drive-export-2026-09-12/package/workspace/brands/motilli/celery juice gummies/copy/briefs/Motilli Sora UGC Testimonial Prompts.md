# Motilli — Sora 2 Pro UGC Testimonial Prompts

5 standalone AI-generated testimonial clips. Each features a different woman over 50 currently on GLP-1 medications, reviewing Motilli from a different symptom angle. Each prompt is fully self-contained — Sora has no memory between generations.

**Platform:** Sora 2 Pro
**Aspect Ratio:** 9:16 vertical (Instagram/Facebook/TikTok)
**Clip Length:** 12 seconds max each
**Audio:** Record separately or use ElevenLabs TTS. These prompts generate the VIDEO only.
**Post-Production:** Add audio sync + captions in CapCut. No text is baked into the video prompts.

## Production Notes

**Audio sync:** Generate each video clip first, then record or generate the matching audio (ElevenLabs recommended for consistency). Sync in CapCut using the lip movement as a guide — Sora's lip movement won't perfectly match but CapCut's auto-sync handles the rest.

**Captions:** Add burned-in captions in CapCut post-production. Use a bold white font with a dark shadow or background bar. Highlight key phrases ("three days," "sulfur burps are completely gone," "like clockwork") in Motilli green (#95C537) or yellow.

**Thumbnail frames:** Pull the most expressive frame from each clip for the video thumbnail. The best frame is usually the gesture moment (hand on stomach, holding up two fingers, leaning forward).

**Batch generation tip:** If Sora struggles with face consistency, generate 3-4 versions of each prompt and pick the most natural-looking one. The car interior prompts (1 and 5) tend to be most consistent because the background is simple and dark.

**Ad deployment:** Each clip works as a standalone 12-second testimonial ad. They also work stitched together as a 60-second compilation with transitions ("Real women. Real GLP-1 side effects. Real results.") added in post.
